## 3. 状态联动落点

| 联动链路 | 统一状态动作 | 验收结果 |
| --- | --- | --- |
| 创建 → 上架 → 广场可见 | `createResource`、`togglePublish` | 已实现 |
| 直接获取 → 当前空间我的资源 | `acquire` | 已实测通过 |
| 申请 → 待审批 → 审批通过 → 我的资源 | `applyForResource`、`reviewApplication` | 已实测通过 |
| 安装 → 失败/完成 → 重新安装 | `installResource`、`batchInstall` | 已实现 |
| 公开策略变化 → 获取方式变化 | `setStrategy`、`getAccess` | 已实现 |
| 撤销/到期/删除 → 我的资源失效 | `revokeGrant`、到期字段、`deleteResource` | 已实现 |
| 工作空间切换 → 获取状态及我的资源切换 | `WorkspaceContext` + `spaceId` 授权关系 | 已实现 |
