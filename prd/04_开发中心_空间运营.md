## 空间运营需求设计

空间运营面向当前进入空间的管理者（空间创建人或管理员），提供空间内部的高集成度运营管理能力。与运维中心全局视角不同，空间运营聚焦于**当前空间内部**，包含统计分析和空间管理两个菜单项：统计分析为运营数据仪表盘，空间管理以 Tab 形式聚合基本信息、成员管理、操作日志。资源配额的设置权限归属更高级别的管理员，在运维中心全局空间管理中统一配置，统计分析仅以只读方式展示当前配额用量。

***

### 一、统计分析

统计分析是进入空间运营后的默认首页，以仪表盘形式展示当前空间的运营全貌与使用概况。

#### 1.1 页面布局

- 顶部：当前空间信息横条（空间图标 + 空间名称 + 空间类型/角色标签 + 创建时间 + 最近更新时间），右侧包含时间范围选择器（近一天 / 近七天 / 近三十天）
- 指标卡片行（6 张横排）
- 配额使用概览行（5 张进度条卡片，只读）
- 图表区（两行各 2 张，共 4 张图表）
- 资源明细区（最近智能体、最近知识库）

#### 1.2 指标卡片行

| 卡片   | 说明                           |
| ---- | ---------------------------- |
| 智能体数 | 当前空间内智能体总数                   |
| 知识库数 | 当前空间内知识库数量                   |
| 提示词数 | 提示词仓库内条目数                    |
| 工具数  | 已接入的工具组件数量                   |
| 模型数  | 已接入的大模型数量                    |
| 连接器数 | 已接入的连接器数量                    |

卡片仅展示数量，不展示配额上限。

#### 1.3 配额使用概览（只读）

指标卡片行下方以一行 5 张小型进度条卡片展示当前配额用量（只读，不可编辑）：

| 配额项     | 说明                           |
| ------- | ---------------------------- |
| 每日 Token 配额  | 本日已用 / 日上限，进度条 + 百分比 |
| 每月 Token 配额  | 本月已用 / 月上限，进度条 + 百分比 |
| 存储空间配额  | 已用存储 / 总上限，进度条 + 百分比         |
| 智能体数量配额 | 已创建 / 上限，进度条 + 百分比           |
| 成员数量配额 | 当前成员数 / 上限，进度条 + 百分比           |

每张配额卡片底部显示当前使用百分比。

#### 1.4 图表区

| 图表         | 类型    | 说明                   |
| ---------- | ----- | -------------------- |
| 近三十天调用量趋势  | 面积图   | 按日展示该空间内所有智能体的调用次数变化 |
| 智能体类型分布    | 环形图   | 标准 / 流程 / 自主智能体占比    |
| Token 消耗趋势 | 折线图   | 按日展示输入/输出 Token 消耗变化 |
| 活跃成员 TOP10 | 横向条形图 | 按活跃度降序展示空间内最活跃的成员    |

#### 1.5 资源明细

空间内各类资源的快速入口列表：

- 智能体列表（展示最近创建的 5 个智能体，含名称、类型、状态、创建时间，「查看全部」链接）
- 知识库列表（展示最近创建的 5 个知识库，含名称、文档数、状态，「查看全部」链接）

***

### 二、空间管理

空间管理将基本信息编辑、成员管理、操作日志聚合为单页，通过顶部 Tab 切换，避免菜单膨胀。页面顶部以横条展示当前空间基本信息（空间图标 + 空间名称 + 空间类型标签 + 创建时间 + 创建人）。

#### 2.1 Tab 1：基本信息

编辑空间的基本属性信息，默认只读展示，点击「编辑」按钮进入可编辑状态：

| 字段      | 说明                    |
| ------- | --------------------- |
| 空间名称    | 文本输入，必填 |
| 空间描述    | 文本域，选填                |
| 空间图标    | 图标选择器，从预设库中选择或上传自定义图标 |
| 所属警种/部门 | 下拉选择，可修改 |
| 空间类型 | 只读展示，不可修改（由创建时确定） |
| 创建人     | 只读                    |
| 创建时间    | 只读                    |

编辑态下显示「保存」「取消」按钮，保存后空间名称和图标实时更新至工作空间切换器。

#### 2.2 Tab 2：成员管理

提供当前空间内成员的查看、添加、角色变更与移除能力。

**个人空间**：仅展示创建人信息，不支持添加其他成员，提示用户切换到工作空间进行多人协作。

**工作空间 / 专案空间**：

**搜索栏**：按姓名或部门搜索 + 角色筛选下拉（全部/创建人/管理员/普通用户）+「添加成员」按钮。搜索栏与下方表格列头左对齐。

**成员列表**（表格形式）：

| 列名   | 说明                            |
| ---- | ----------------------------- |
| 成员   | 头像 + 姓名 + 所属部门                |
| 角色   | 标签：创建人（金色）/ 管理员（蓝色）/ 普通用户（灰色） |
| 加入时间 | 被添加至空间的时间                     |
| 最近活跃 | 最近一次在空间内操作的时间                 |
| 操作   | 「变更角色」下拉 +「移除」按钮（创建人不可移除或降级，按钮置灰） |

**添加成员**：点击「添加成员」弹出对话框，使用人员多选下拉组件。下拉选项展示头像、姓名、部门，支持按姓名/部门搜索。指定初始角色（管理员/普通用户，默认普通用户）。

**变更角色与移除**：变更角色在下拉中选择即刻生效；移除弹出二次确认后记录日志。

#### 2.3 Tab 3：操作日志

提供当前空间内所有关键操作的审计记录。

**筛选栏**（横排）：

- 搜索框（按操作人或操作对象搜索）
- 日期范围选择器

**日志列表**（表格形式）：

| 列名   | 说明                |
| ---- | ----------------- |
| 时间   | 操作发生的精确时间         |
| 操作人  | 姓名                |
| 操作类型 | 彩色标签              |
| 操作对象 | 具体资源名称            |
| 操作   | 「详情」按钮，点击弹出弹窗展示完整 JSON |

仅展示不可编辑，支持分页（默认每页 20 条），支持导出。

**导出功能**：筛选栏右侧提供「导出」按钮，点击后将当前筛选条件下的操作日志导出为 Excel 文件（CSV 格式），包含时间、操作人、操作类型、操作对象及详情等全部字段。

#### 2.4 通用交互行为

- 统计分析中点击智能体数/知识库数卡片分别跳转至对应开发功能模块
- Tab 切换时保留当前 Tab 内的筛选状态
- 所有涉及列表的页面均支持分页
- 操作日志仅展示当前空间的数据，不跨空间查询
