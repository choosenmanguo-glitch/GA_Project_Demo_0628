## 智能体配置需求设计

智能体创建完成后，进入统一的配置页面。该页面为所有三种智能体类型提供一致的导航框架，但「配置」页的内容根据智能体类型不同而呈现不同的界面。

***

### 一、页面布局

```
┌─────────────────────────────────────────────────┐
│  [← 返回]  智能体名称                             │  ← 顶部标题栏
├──────────┬──────────────────────────────────────┤
│ 智能体信息  │                                      │
│ 卡片      │                                      │
│          │        配置 / 发布 / 日志 / 统计         │  ← 右侧主内容区
│ 配置      │         （当前选中页面的内容）             │
│ 发布      │                                      │
│ 日志      │                                      │
│ 统计      │                                      │
│          │                                      │
└──────────┴──────────────────────────────────────┘
```

- **顶部标题栏**：左侧「← 返回」按钮（返回智能体管理列表）+ 当前智能体名称
- **左侧导航**（宽度约 200px）：自上而下排列以下导航项
- **右侧主内容区**：根据左侧选中导航项切换内容

### 二、左侧导航项

| 导航项     | 说明                                                                                                                                    |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 智能体信息卡片 | 固定在导航顶部。展示智能体头像、名称、类型标签（标准/流程/自主）、当前状态（草稿/已发布/已下架）。点击卡片右侧的编辑图标（✎），从右侧弹出抽屉，可编辑智能体名称、描述和头像。智能体类型和子类型在抽屉中展示但不可编辑（置灰锁定）。保存后即时更新卡片和顶部标题栏信息 |
| 配置      | 智能体的核心配置页，根据智能体类型呈现不同的配置界面（详见 三）                                                                                                      |
| 发布      | 将当前配置版本发布至正式环境，对目标用户即时生效。详见「四、发布页」                                                                                                    |
| 日志      | 查看当前智能体的对话会话记录与操作变更历史。默认展示对话日志（详见「六、日志页」），支持切换至操作日志查看配置变更记录                                                                 |
| 统计      | 查看当前智能体运营数据的多维度统计看板，覆盖核心指标、趋势分析、排行与用户反馈。详见「五、统计页」 |                                          |

### 三、配置页：页面内部布局

点击左侧「配置」导航项后，右侧内容区采用「顶部工具栏 + 左下配置面板 + 右下测试面板」的三分区布局：

```
┌─────────────────────────────────────────────────────────────────────────┐
│  [保存] [另存为新版本] [版本列表 ▼]  [草稿] [发布]    v1.2.3 · 上次保存   │
│                                          14:30:22 · 自动保存：开启       │  ← 顶部操作栏
├──────────────────────────────┬──────────────────────────────────────────┤
│                              │                                          │
│     配置面板（可滚动）         │     测试面板                              │
│                              │                                          │
│   · 模型选择                 │   ┌────────────────────────────────────┐ │
│   · 提示词编排               │   │ 你好，我是XXX智能体                  │ │
│   · 知识库关联               │   │                                    │ │
│   · 文件上传                 │   │ [用户输入区域]                      │ │
│   · 工具挂载                 │   │                                    │ │
│   · 对话交互                 │   │ [发送]                             │ │
│                              │   └────────────────────────────────────┘ │
│                              │                                          │
│                              │  输出指标：延迟 / Token /                 │
│                              │  知识库命中 / 工具调用次数                 │
└──────────────────────────────┴──────────────────────────────────────────┘
```

各区域详细说明：

**顶部操作栏**（通栏，高度约 64-80px，两行排列。固定在顶部，下方区域滚动时保持可见）：

*第一行：操作按钮*

| 元素       | 说明                                                                                                                                                                                                   |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 保存按钮     | 主按钮（Primary），保存当前配置。校验必填字段，通过后 Toast 提示"保存成功"，更新最近保存时间。存在未保存改动时按钮以更高饱和度的主题色高亮提示用户                                                                                                                    |
| 另存为新版本   | 次按钮（Default）。将当前配置保存为一个新的草稿版本，不覆盖当前正在编辑的版本。点击弹出轻量弹窗，填写版本说明（选填，最多 200 字），确认后生成新版本并自动切换至新版本继续编辑                                                                                                        |
| 版本列表     | 下拉菜单按钮（带向下箭头图标）。展开后列出所有历史版本，每条包含：版本号、发布时间（或草稿标记）、版本说明摘要、当前生效标记（绿色圆点）。菜单内每条版本支持三项操作——① 查看快照：以只读模式打开该版本的完整配置，不可编辑，顶部显示"正在查看 v1.x 版本快照"提示条；② 恢复为草稿：将该版本内容复制为当前草稿，覆盖当前未保存内容前弹出二次确认；③ 删除：仅草稿状态或非当前生效版本可删除 |
| 草稿/已发布标签 | Tag 组件，展示当前选中版本的状态。草稿显示橙色"草稿"标签，已发布显示绿色"已发布"标签。发布操作成功后自动刷新标签状态                                                                                                                                       |
| 发布按钮     | 快捷发布入口。点击后若当前配置有未保存改动则先触发保存，保存成功后跳转至左侧导航「发布」页；若无未保存改动则直接弹出简化发布确认框（输入版本说明 + 确认发布按钮），发布成功后 Toast 提示并更新版本状态标签                                                                                           |

*第二行：状态信息（右对齐，灰色小字）*

| 元素     | 说明                                                                       |
| ------ | ------------------------------------------------------------------------ |
| 当前版本号  | "版本 v1.2.3"，与版本列表中当前编辑/查看的版本号一致                                          |
| 最近保存时间 | 格式"上次保存：2026-06-26 14:30:22"，手动保存或自动保存后实时刷新                              |
| 自动保存状态 | "自动保存：开启"（绿色文字）或"自动保存：关闭"（灰色文字）。自动保存间隔可由系统设置控制，默认每 30 秒检查是否有改动并自动保存为临时草稿 |

**左下配置面板**（占比约 50%-60%，可独立纵向滚动）：

- 配置面板根据智能体类型展示不同的配置内容（详见下方第四、五、六章按类型区分）
- 配置面板顶部固定显示当前正在编辑的配置区块名称（如"模型选择"），下方区块内容可滚动
- 各配置区块之间以分割线或卡片形式分隔，区块标题可点击折叠/展开
- 当右下测试面板对话引用某个配置区块（如点击调试输出中的"提示词"链接），左侧自动滚动定位到对应区块并高亮

**右下测试面板**（占比约 40%-50%，独立滚动，内容固定不随左侧滚动）：

| 区块    | 说明                                                                                                                                                                                                                                     |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 对话预览区 | 模拟终端用户与智能体对话的聊天界面。顶部展示智能体头像、名称、开场白。用户输入消息后，以当前配置面板中的临时配置（无需保存即可生效）发起模拟对话。对话气泡区分用户消息（右侧蓝色）和智能体回复（左侧灰色），支持 Markdown 渲染                                                                                                                   |
| 输入区   | 底部固定输入框 + 发送按钮。支持多行输入（TextArea 可拖拽调整行数），Shift+Enter 换行，Enter 直接发送。提供上传文件按钮（回形针图标），支持上传文档（PDF/Word/TXT）或图片用于测试文件上传配置效果。上传的文件仅用于本次测试会话，不持久化                                                                                              |
| 调试输出  | 每条智能体回复下方附带可折叠的"调试详情"区域（默认折叠）。展开后以 Tab 或折叠面板形式展示：① 最终拼装的提示词全文（Markdown 代码块）；② 模型请求参数（JSON 格式、含 model/temperature/max\_tokens/messages 等）；③ 模型原始响应（JSON 格式）；④ 知识库检索命中片段列表（含片段内容、来源文档、相似度分数）；⑤ 工具调用详情（工具名称、入参、出参、调用耗时 ms）。所有代码块右上角提供复制按钮 |
| 输出指标  | 每次对话后在最下方实时更新指标行：首 Token 延迟（ms）、总响应耗时（ms）、输入 Token 数、输出 Token 数、知识库命中片段数、工具调用次数及总耗时。若某指标不适用（如未配置知识库），显示"—"                                                                                                                             |
| 重置对话  | 清空按钮（链接样式或文字按钮），点击后清除所有对话记录和调试输出，恢复到初始开场白状态，同时重置所有输出指标                                                                                                                                                                                 |

***

### 四、发布页

发布页是智能体从开发态交付至生产环境的核心枢纽，提供「发布前校验 → 发布信息填写 → 多渠道发布与管理」的完整闭环。

#### 4.1 页面整体布局

发布页采用单列居中布局，最大宽度 720px，内容从上至下依次为：

```
┌──────────────────────────────────────────────────┐
│                                                  │
│   ┌─ 发布前校验 ─────────────────────────────┐   │
│   │  ✓ 配置完整性检查                         │   │
│   │  ✓ 模型连通性检查                         │   │
│   │  ✓ 知识库连通性检查（如有）                │   │
│   │  ✓ 工具授权校验（如有）                    │   │
│   │  ✗ 前置条件提示（如不通过则阻断发布）       │   │
│   └──────────────────────────────────────────┘   │
│                                                  │
│   ┌─ 发布信息 ───────────────────────────────┐   │
│   │  发布版本     v1.3.0                     │   │
│   │  版本说明     [输入框，最多 200 字]        │   │
│   │  智能体简称   [输入框]                    │   │
│   │  所属分类     [下拉选择]                  │   │
│   │  全局权限模式 [完全公开 / 公开可见授权使用  │   │
│   │               / 完全授权]                 │   │
│   └──────────────────────────────────────────┘   │
│                                                  │
│   ┌─ 发布渠道 ───────────────────────────────┐   │
│   │  [✓] 智能体广场   [✓] API接口             │   │
│   │  [ ] 模型上下文协议(MCP)                   │   │
│   │  ─────────────────────────────────────    │   │
│   │  API 接口名称    [输入框]                  │   │
│   │  接口返回类型    [下拉：文本/JSON/流式]     │   │
│   │  请求方式        [下拉：POST/GET]          │   │
│   └──────────────────────────────────────────┘   │
│                                                  │
│   ┌─ 发布历史 ───────────────────────────────┐   │
│   │  v1.2.0  已发布  2026-06-20 14:30        │   │
│   │  v1.1.0  已下架  2026-06-15 10:00        │   │
│   │  v1.0.0  已下架  2026-06-10 09:00        │   │
│   └──────────────────────────────────────────┘   │
│                                                  │
│          [确认发布]                              │
│                                                  │
└──────────────────────────────────────────────────┘
```

#### 4.2 发布前自动校验

点击「发布」导航项后，系统首先执行自动校验。校验项目与规则如下：

| 校验项          | 规则                                                                | 不通过时的行为                                                               |
| ------------ | ----------------------------------------------------------------- | --------------------------------------------------------------------- |
| 配置完整性        | 检查必填配置项是否均已填写：模型选择（已选模型）、提示词编排（内容非空）、对话开场白（内容非空）。标准智能体还需检查其他必填开关项 | 不通过项以红色 ✗ 标记，卡片顶部显示「以下 N 项未通过校验，请修正后再发布」提示条，发布按钮置灰不可点击                |
| 模型连通性        | 向所选模型的供应商接口发送一个轻量探测请求（空 prompt + max\_tokens=1），验证模型服务是否可达、凭证是否有效 | 不通过时标记为警告（黄色 ⚠），允许继续发布但卡片顶部显示警告文案：「模型连通性检测失败，发布后智能体可能无法正常响应。建议修正后再发布」 |
| 知识库连通性（如有配置） | 对关联的知识库发送查询探测（空查询 + top\_k=1），验证知识库服务及向量索引是否正常                    | 不通过时标记为警告，处理逻辑同模型连通性                                                  |
| 工具授权校验（如有配置） | 检查已挂载工具的授权凭证是否有效，token/API key 是否过期或已撤销                           | 不通过时标记为警告，提示具体哪个工具的授权异常                                               |

校验结果以卡片形式展示，每项校验前有对应的图标：通过（✓ 绿色）、警告（⚠ 黄色）、不通过（✗ 红色）。校验不通过（红色项）阻断发布，警告项不阻断但提示风险。

校验完成后执行过程写入版本操作日志。

#### 4.3 发布信息填写

校验通过后，进入发布信息填写区域：

| 字段     | 说明                                                                                                                                                                           |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 发布版本   | 自动带入当前正在编辑的版本号，只读展示                                                                                                                                                          |
| 版本说明   | TextArea 输入框，选填，最多 200 字。用于记录本次发布的核心变更点（如"新增文件审核能力""修复模型温度参数"），发布后在版本列表中展示                                                                                                   |
| 智能体简称  | Input 输入框，必填，最多 20 字。用于在智能体广场中展示的短名称                                                                                                                                         |
| 所属分类   | Select 下拉选择，必填。可选分类：客服应答、业务审核、知识问答、数据分析、文档编写、智能检索、智能抽取、智能分类、自定义分类等                                                                                                           |
| 全局权限模式 | Radio.Group 单选框，必填，默认选中「完全授权」。三种模式：① **完全公开**——所有用户无需授权即可在广场中查看和使用该智能体；② **公开可见但授权使用**——所有用户可在广场中看到该智能体，但需管理员授权后方可使用；③ **完全授权**——仅授权范围内的部门/岗位/人员可在广场中看到并使用该智能体。权限模式切换时弹出二次确认 |

选定「公开可见但授权使用」或「完全授权」模式后，下方展开授权对象配置区域（详见 §4.7 权限配置）。

#### 4.4 发布渠道配置

发布页支持勾选将智能体发布到一种或多种渠道：

| 渠道           | 说明                                                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------------------------------------- |
| 智能体广场        | 默认勾选。将智能体发布至平台智能体广场，供内部用户浏览、搜索和使用。发布后依据全局权限模式控制可见与使用范围                                                                     |
| API 接口       | 可选勾选。勾选后系统自动为智能体生成标准化接口，外部系统可通过 API 调用智能体的推理与对话能力。勾选后展开 API 配置项（接口名称、返回类型、请求方式）。发布成功后自动生成接口密钥和调用文档。智能体后续更新发布版本时，接口定义自动同步刷新 |
| 模型上下文协议（MCP） | 可选勾选（仅自主智能体支持）。勾选后系统将智能体注册为符合 MCP 协议规范的服务端，标准 MCP 客户端可通过协议自动发现并调用该智能体。勾选后展开 MCP 配置项（服务名称、版本号、暴露类型：工具类/资源类，服务描述）            |

**API 接口配置项**（勾选 API 接口后展开）：

| 字段   | 说明                                                      |
| ---- | ------------------------------------------------------- |
| 接口名称 | 外部调用方看到的接口名称标识，必填                                       |
| 返回类型 | 下拉选择：JSON（结构化 JSON 响应）、文本（纯文本 Markdown 响应）、流式（SSE 流式推送） |
| 请求方式 | 下拉选择 POST 或 GET                                         |

**MCP 配置项**（勾选 MCP 后展开）：

| 字段   | 说明                            |
| ---- | ----------------------------- |
| 服务名称 | MCP 服务端的名称标识，必填               |
| 版本号  | 服务版本号，如 1.0.0，必填              |
| 暴露类型 | Tool（工具类）或 Resource（资源类），必填   |
| 服务描述 | 供 MCP 客户端自动发现时识别智能体功能的描述文本，必填 |

#### 4.5 执行发布

发布信息填写完整后，点击「确认发布」按钮，系统校验所有必填项，通过后将智能体发布至所选渠道（广场/API/MCP），状态变更为「已发布」。若勾选了 API 渠道，自动生成接口密钥凭证并展示密钥明文（仅展示一次）；若勾选了 MCP，生成服务接入信息。全程写入操作日志。

发布成功后 Toast 提示「发布成功」，左侧导航智能体信息卡片的状态标签同步更新为「已发布」；版本列表中当前版本标记为绿色「已发布」标签；顶部操作栏状态标签联动更新。

#### 4.6 发布后管理

发布成功后，发布页提供以下后续管理能力：

**4.6.1 查看发布状态与渠道**

| 功能      | 说明                                                              |
| ------- | --------------------------------------------------------------- |
| 查看已发布渠道 | 展示智能体当前在哪些渠道处于发布状态（智能体广场 / API 接口 / MCP），及每个渠道的发布版本号和发布时间       |
| 查看授权范围  | 查看已发布智能体当前的可见和使用授权范围，包括全局权限模式、已授权的部门及人员清单                       |
| 查看接入信息  | 查看 API 接口的调用地址、请求示例和返回示例；查看 MCP 服务的端点地址、协议标识符和鉴权密钥。所有接入信息支持一键复制 |

**4.6.2 接口密钥管理**（已发布为 API 接口或 MCP 后可见）

| 操作      | 说明                                                          |
| ------- | ----------------------------------------------------------- |
| 密钥列表    | 列表展示所有已创建的密钥：接入方名称、备注、访问量、启用状态、创建时间。支持分页和按接入方名称搜索           |
| 创建密钥    | 填写接入方名称和备注，系统自动生成唯一密钥凭证并默认启用。创建成功后可立即复制密钥内容（仅展示一次，后续不可查看明文） |
| 编辑密钥    | 修改已有密钥的接入方名称和备注。保存后记录更新人及更新时间，写入操作日志                        |
| 删除密钥    | 删除不再使用的密钥。若密钥为启用状态则拦截并提示；删除前弹出二次确认；删除后密钥立即失效                |
| 停用/启用密钥 | 停用后该密钥无法通过认证；启用后恢复有效性。状态变更实时生效，操作记录日志                       |

**4.6.3 撤回发布**

| 操作   | 说明                                                                                                                       |
| ---- | ------------------------------------------------------------------------------------------------------------------------ |
| 撤回发布 | 对已发布至广场的智能体发起撤回。填写撤回原因后确认撤回，智能体从广场移除，状态变更为「已下架」。撤回后智能体的配置数据完整保留，后续可重新发布上线。若同时发布了 API/MCP 渠道，撤回时一并处理对应渠道的密钥失效和接入信息更新 |
| 重新发布 | 对已下架的智能体，修改配置后可重新走发布流程（校验 → 填写信息 → 确认发布）                                                                                 |

#### 4.7 权限配置

权限配置为发布流程中的可选步骤，适用于全局权限模式选择「公开可见但授权使用」或「完全授权」的场景。

**4.7.1 全局权限模式**

| 模式        | 说明                                   |
| --------- | ------------------------------------ |
| 完全公开      | 所有用户无需授权即可在广场中查看和使用该智能体。无需进一步配置      |
| 公开可见但授权使用 | 所有用户可在广场中看到该智能体，但需管理员授权后方可使用。需配置授权对象 |
| 完全授权      | 仅授权范围内的对象可在广场中看到并使用该智能体。需配置授权对象      |

**4.7.2 授权对象管理**

| 操作      | 说明                                                  |
| ------- | --------------------------------------------------- |
| 搜索授权对象  | 输入对象名称关键字，结合对象类型（个人/部门/岗位）和授权级别（仅可见/可见可使用）进行组合筛选    |
| 添加授权对象  | 从组织架构中批量选取个人、部门或岗位，指定授权级别。系统校验是否已存在授权记录避免重复，保存后即时生效 |
| 变更授权级别  | 将已授权对象的权限级别在「仅可见」与「可见可使用」之间调整，保存后即时生效               |
| 设置授权有效期 | 设定权限失效日期，或修改为永久有效                                   |
| 移除授权对象  | 取消指定对象权限，弹出二次确认后即时生效                                |

**4.7.3 权限变更记录**

| 功能     | 说明                                                                           |
| ------ | ---------------------------------------------------------------------------- |
| 查看变更记录 | 列表展示操作类型（添加授权/变更级别/移除授权/调整有效期）、操作人、被授权对象、变更前后权限快照、操作时间。支持按操作人、被授权对象、时间范围组合检索 |
| 自动记录   | 系统在授权对象增减、级别变更、有效期调整或移除时自动写入变更日志                                             |
| 权限配置记录 | 记录每个智能体的全局权限模式及授权对象配置，含配置记录 ID、智能体 ID、全局权限模式、启用状态、最近更新人、最近更新时间               |

#### 4.8 发布记录与历史

| 功能     | 说明                                                                                           |
| ------ | -------------------------------------------------------------------------------------------- |
| 发布记录列表 | 「发布历史」区域按时间倒序展示该智能体的历次发布记录，每条包含：版本号、发布状态（已发布/已下架）、发布时间、发布人、版本说明摘要。当前生效的已发布版本以绿色圆点标记 |
| 发布详情   | 点击某条发布记录展开详情，展示：发布版本号、版本说明全文、发布渠道、权限模式。 |
| 操作日志联动 | 每次发布、撤回、权限变更操作均自动写入日志页（左侧导航「日志」），支持跨页面追溯                                                  |

#### 5.2 时间范围选择

| 元素 | 说明 |

| 指标 | 说明 | 趋势对比 |
|------|------|----------|
| 累计用户数 | 使用过该智能体的总用户数（UV）。已注册并至少发起过一次对话的用户计入 | 相较于上一个等长周期，展示变化百分比和方向箭头（▴ 绿色上升 / ▾ 红色下降） |

| 累计 Token 消耗 | 智能体运行过程中产生的输入 + 输出 Token 总量。格式如 2.8M / 586K | 同上，展示周/月环比变化 |

**明细内搜索**：
- 面板内嵌搜索条，输入关键词在对话内容中实时高亮定位
- 支持按角色（全部/用户/智能体）、是否报错快速过滤对话轮次

#### 6.6 操作日志 - 子标签

切换至「操作日志」子标签后，展示该智能体的配置变更历史时间线：

| 字段   | 说明                             |
| ---- | ------------------------------ |
| 时间   | 操作发生时间，精确到秒                    |
| 操作人  | 执行操作的用户姓名                      |
| 操作类型 | 创建 / 修改配置 / 发布 / 下架 / 版本恢复等     |
| 变更摘要 | 操作的具体描述（如"更新提示词内容，调整模型温度参数"）  |

操作日志仅展示、不可编辑删除，支持分页。

#### 6.7 通用交互行为

- 会话列表支持**自动刷新**（默认关闭，可开启 30 秒间隔）
- 明细面板支持**独立滚动**，不影响列表浏览
- 列表和明细均提供「导出」功能：
  - 列表导出：将当前筛选条件下的会话列表导出为 Excel
  - 明细导出：将单次会话的完整对话内容导出为 PDF，含排版渲染

### 八、流程智能体 - 集成 Dify 编排页面

流程智能体的配置直接嵌入 Dify 平台的工作流编排界面。页面加载时通过 iframe 或微前端方式加载 Dify 的画布编辑器，用户在统一框架内完成节点拖拽、连线编排、变量配置、在线调试和版本管理等操作。

流程智能体模式下，配置面板占满左侧区域（Dify 画布编辑器），测试面板在右侧展示 Dify 的内置调试对话窗口。顶部操作栏保持不变，保存按钮触发 Dify 侧的保存操作。

Dify 内部的发布操作与本平台的「发布」导航项同步——在 Dify 中发布后，本平台同步更新智能体版本状态。Dify 操作产生的变更自动记录至本平台的操作日志。

### 九、自主智能体 - 集成 Dify 对应页面

自主智能体的配置直接嵌入 Dify 平台的自主智能体配置界面，涵盖代理策略选择、模型与参数配置、指令编排、工具集授权、知识库关联、对话交互设置、在线调试和版本管理等能力。

加载和布局方式与流程智能体一致。顶部操作栏保持不变，Dify 侧操作与本平台日志、统计、发布状态保持同步。

### 十、通用交互行为

- 配置页面左侧导航项切换时，右侧内容区平滑刷新，若存在未保存的配置改动弹出提醒确认
- 智能体信息卡片中的名称、描述、头像修改即时保存（失焦或回车自动提交）
- 日志和统计数据随左侧导航切换实时加载，默认展示近七天数据
- 返回按钮点击时，若有未保存的配置改动，弹出提醒确认
- 标准智能体配置页面中，模型列表、知识库列表、工具列表、提示词模板均从当前空间数据源动态拉取
