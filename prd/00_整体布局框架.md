产品定位：组织级的智能体开发平台

## 整体布局框架

平台采用经典的"顶栏 + 左侧导航 + 右侧内容区"三段式布局，以最大化内容展示效率、减少层级跳转为目标。通用交互容器按照复杂度递增分为四种：四级页面内嵌控件、右侧抽屉、二级页面、模态弹窗。

***

### 一、顶栏

顶栏固定在页面最上方，高度 56px，始终可见。

| 区域 | 组件                     | 说明                                                       |
| -- | ---------------------- | -------------------------------------------------------- |
| 左侧 | 平台 Logo + 名称（鲁警智算开发平台） | 点击回到首页                                                   |
| 中间 | 一级导航                   | 横向排列的一级导航项（首页/应用中心/开发中心/运维中心/管理中心），当前选中项高亮，点击切换一级模块 |
| 右侧 | 功能入口组                  | 从左至右依次排列                                                 |

**右侧功能入口**：

| 入口     | 交互       | 说明                           |
| ------ | -------- | ---------------------------- |
| 鲁警门户   | 点击跳转     | 跳转至鲁警门户页面                    |
| 全局助手图标 | 点击弹出右侧抽屉 | 在页面右侧弹出全局智能助手抽屉，提供问答、快捷操作等能力 |
| 消息图标   | 点击弹出下拉面板 | 展示系统通知和消息列表，未读消息数角标提示        |
| 用户信息   | 点击弹出下拉菜单 | 展示头像、姓名、所属部门，提供个人设置和退出登录入口   |

***

### 二、左侧导航

左侧导航宽度 220px，跟随一级导航切换内容，展示当前一级模块下的菜单树。

| 元素    | 样式        | 说明                               |
| ----- | --------- | -------------------------------- |
| 菜单组标签 | 灰色小字，不可点击 | 对菜单项进行视觉分组，如"资源监控"、"运营洞察"、"运维监控" |
| 菜单项   | 黑色文字，可点击  | 点击切换右侧内容区，当前选中项高亮（蓝色背景或左侧蓝色竖条）   |

**特殊组件**：开发中心左侧导航顶部嵌入「工作空间切换器」，展示当前进入的空间名称和图标，点击可切换空间，非菜单项。

***

### 三、右侧页面区域

右侧内容区是主体工作区，随左侧菜单切换加载对应页面视图。

#### 3.2 页签栏

在右侧内容区顶部、页面标题栏之上，提供「已打开页签」栏，方便用户在多页面间快速切换。

| 元素       | 说明 |
| -------- | ---- |
| 页签项 | 每个已打开的页面以页签形式横向排列，显示页面名称。当前页面页签高亮（蓝色文字 + 蓝色下划线 + 圆点指示器）。点击页签切换至对应页面。 |
| 关闭按钮 | 每个页签右侧有 ✕ 关闭按钮，始终可见，hover 时加深颜色并出现浅灰背景。关闭当前页签后自动跳转至相邻页签。 |
| 滚动遮罩 | 页签数量超出可视宽度时自动出现右侧渐变遮罩，暗示可横向滚动。 |
| 持久化 | 页签栈通过 sessionStorage 持久化，刷新页面后保持。默认始终保留至少一个页签（工作台）。 |

#### 3.3 页面顶部标题栏

| 组件       | 说明                                    |
| -------- | ------------------------------------- |
| 面包屑 / 返回 | 一级页面仅展示页面标题；二级页面展示"（返回）一级页面名 / 二级页面名" |
| 页面标题     | 当前页面的名称                               |
| 提示图标     | 点击弹出气泡提示框，展示当前页面的功能说明和使用指引            |

#### 3.4 三级导航 Tab

对于需要分组管理内容、但独立菜单项太细碎的页面（如空间管理、告警监控），在页面内以 Tab 导航承载子级视图。Tab 位于页面标题栏下方，横向排列，当前选中 Tab 高亮。

典型用例：

- 告警监控：告警记录 / 告警规则
- 空间管理：基本信息 / 成员管理 / 操作日志 / 高级操作
- 空间管理详情面板：基本信息 / 成员管理 / 资源配额 / 操作日志
- 智能体监控详情页：概览 / 使用统计 / 使用日志

#### 3.5 管理页面通用内容区

管理页面（列表型或仪表盘型）按以下结构从上到下组织：

| 区域           | 说明                                                                                                                                              |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 数据指标卡片区      | 4-5 张横排统计卡片，展示核心 KPI，部分卡片可点击下钻                                                                                                                  |
| 筛选区 + 页面级操作区 | 横排一行，左右分区。左侧：多条件筛选组件（下拉、搜索、日期选择器等，若组件数量超出单行容纳范围则仅展示主要筛选组件，末尾显示「更多筛选」按钮，点击展开剩余筛选项）+「搜索」「重置」按钮 + 列表/卡片视图切换按钮组（默认列表，选中态高亮）。右侧：页面级操作按钮（如新建、批量操作、导出） |
| 列表 / 卡片      | 数据展示的主体区域。列表视图以表格形式展示，卡片视图以网格形式展示（适用于更强调可视化摘要的场景，如空间管理、资源广场），两种视图切换后筛选条件和分页状态保持不变                                                               |
| 分页器          | 列表底部居右，默认每页 10 条，支持切换每页条数                                                                                                                       |

### 四、交互容器分级

根据内容复杂度和上下文关系，采用四种交互容器承载不同场景：

| 容器   | 使用场景                              | 宽度                                          | 行为                                         |
| ---- | --------------------------------- | ------------------------------------------- | ------------------------------------------ |
| 右侧抽屉 | 大部分表单、详情查看、配置面板。不影响当前页面的上下文浏览     | 根据内容量选择 45%-60% 宽度（如智能体监控详情 45%、新建告警规则 50%） | 从右侧滑入，背景半透明遮罩，点击遮罩或关闭按钮关闭，关闭时若有未保存内容弹出确认提示 |
| 二级页面 | 非常复杂、需要全屏承载的内容（如智能体构建编排画布、测评结果报告） | 全宽                                          | 页面整体跳转，顶部带返回面包屑                            |
| 模态弹窗 | 仅确认操作或极简表单（如删除确认、变更角色、设置配额数值）     | 居中固定宽度（约 420px-520px）                       | 居中弹出，点击遮罩或取消按钮关闭                           |
| 气泡弹窗 | 非关键确认或轻量提示（如即将离开页面的提醒、保存成功 Toast） | 自适应                                         | 短暂自动消失或点击外部关闭                              |
