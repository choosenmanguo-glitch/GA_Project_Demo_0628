### 三、运营洞察

运营洞察从人员组织视角出发，提供按部门、按空间、按用户三个维度的运营数据钻取与对比分析能力，帮助管理者掌握平台在各组织单元的推广使用情况。三个维度各对应一个独立菜单项，点击左侧菜单切换页面。

各页面采用统一的**顶部筛选 + 全宽仪表盘**布局：页面顶部为分析对象选择器 + 时间范围，选中对象后下方全宽展示该对象的运营仪表盘。

#### 3.1 部门分析（菜单项：部门分析）

页面顶部为部门选择区与时间筛选栏，下方全宽展示选中部门的运营仪表盘。

**顶部筛选区**：

| 组件   | 说明                                                                     |
| ---- | ---------------------------------------------------------------------- |
| 部门选择 | 下拉搜索选择器，输入部门名称关键字模糊匹配，选中后下方仪表盘联动刷新。右侧附带「多选对比」开关，开启后可追加选择最多 5 个部门进入对比模式 |
| 时间范围 | 近一天 / 近七天 / 近三十天 / 自定义                                                 |

**全局指标卡片行**（4 张横排，对比模式下切换为多部门对比表格）：

- 活跃用户数：该部门近三十天有操作记录的用户数
- 累计调用次数：该部门成员累计调用智能体总次数
- Token 消耗量：该部门累计 Token 消耗
- 创建智能体数：该部门成员创建的智能体总数

**单部门仪表盘**：

| 图表            | 类型    | 说明                  |
| ------------- | ----- | ------------------- |
| 使用次数趋势        | 折线图   | 该部门近三十天使用次数逐日变化     |
| 智能体类型使用分布     | 环形图   | 该部门使用标准/流程/自主智能体的占比 |
| 智能体使用排行 TOP10 | 横向条形图 | 该部门内使用次数最高的 10 个智能体 |
| 活跃用户排行 TOP10  | 横向条形图 | 该部门内活跃度最高的 10 名用户   |

**多部门对比模式**（选中 2-5 个部门时自动切换）：

- 对比指标表格：各部门并列展示活跃用户数、调用次数、Token 消耗、智能体建设数
- 使用趋势对比图：多条折线同图展示各部门使用次数变化
- 智能体类型分布对比：并列柱状图展示各部门标准/流程/自主智能体占比

#### 3.2 空间分析（菜单项：空间分析）

页面顶部为空间选择区与时间筛选栏，下方全宽展示选中空间的运营仪表盘。

**顶部筛选区**：

| 组件   | 说明                                                                         |
| ---- | -------------------------------------------------------------------------- |
| 空间选择 | 下拉搜索选择器，输入空间名称关键字模糊匹配，下拉列表展示空间名称 + 所属警种标签。右侧附带「多选对比」开关，可追加选择最多 5 个空间进入对比模式 |
| 时间范围 | 近一天 / 近七天 / 近三十天 / 自定义                                                     |

**全局指标卡片行**（4 张横排，对比模式下切换为多空间对比表格）：

- 空间成员数
- 智能体总数（已发布/总）
- 近三十天调用次数
- Token 消耗量

**单空间仪表盘**：

| 图表            | 类型    | 说明                  |
| ------------- | ----- | ------------------- |
| 使用次数趋势        | 折线图   | 该空间近三十天调用次数逐日变化     |
| 智能体类型分布       | 环形图   | 标准 / 流程 / 自主智能体占比   |
| 智能体使用排行 TOP10 | 横向条形图 | 该空间内调用次数最高的 10 个智能体 |
| 成员活跃排行 TOP10  | 横向条形图 | 该空间内活跃度最高的 10 名成员   |

**多空间对比模式**（选中 2-5 个空间时自动切换）：

- 对比指标表格：各空间并列展示成员数、智能体数、调用次数、Token 消耗
- 使用趋势对比图：多条折线同图展示各空间调用次数变化
- 资源使用对比：并列柱状图展示各空间模型/知识库/工具使用量

#### 3.3 用户分析（菜单项：用户分析）

页面顶部为用户选择区与时间筛选栏，下方全宽展示选中用户的运营仪表盘。

**顶部筛选区**：

| 组件   | 说明                                                                        |
| ---- | ------------------------------------------------------------------------- |
| 用户选择 | 下拉搜索选择器，输入姓名关键字模糊匹配，下拉列表展示头像 + 姓名 + 所属部门。右侧附带「多选对比」开关，可追加选择最多 5 个用户进入对比模式 |
| 时间范围 | 近一天 / 近七天 / 近三十天 / 自定义                                                    |

**全局指标卡片行**（4 张横排，对比模式下切换为多用户对比表格）：

- 累计使用次数
- Token 消耗量
- 使用的智能体数
- 近三十天活跃天数

**单用户仪表盘**：

| 图表      | 类型  | 说明                                    |
| ------- | --- | ------------------------------------- |
| 使用次数趋势  | 折线图 | 该用户近三十天使用次数逐日变化                       |
| 智能体使用分布 | 饼图  | 该用户使用各智能体的次数占比                        |
| 使用时段分布  | 柱状图 | 按小时统计使用频率（横轴 0-23 时）                  |
| 最近使用记录  | 列表  | 最近 20 条对话记录摘要（智能体名称、时间、Token 消耗、是否报错） |

**多用户对比模式**（选中 2-5 个用户时自动切换）：

- 对比指标表格：各用户并列展示使用次数、Token 消耗、活跃天数、使用智能体数
- 使用趋势对比图：多条折线同图展示各用户使用次数变化

#### 3.4 通用交互行为

- 顶部选择器切换对象后，下方仪表盘**联动刷新**
- 对比模式下，各图表**自动切换**为多系列对比视图
- 所有趋势图支持时间范围联动，与顶部筛选器同步
- 点击任一智能体名称以右侧抽屉打开该智能体的监控详情（见第六节）
- 右上角提供**数据导出**按钮，将当前视图数据导出为 Excel
