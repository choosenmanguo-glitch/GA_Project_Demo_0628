## 运维中心需求设计

运维中心面向平台超级管理员，提供组织级空间统管与全平台运营运维两大核心能力。页面整体采用"左侧导航菜单 + 右侧主内容区"布局。左侧导航以菜单组标签进行视觉分组：空间管理、资源监控、运营洞察和运维监控四个菜单组依次排列，每个菜单组下包含对应的菜单项，点击直接切换右侧对应功能视图。

***

### 一、空间管理

空间管理提供平台全部工作空间的集中管控能力，包括空间创建、编辑、状态管理和配额配置等功能。

#### 1.1 页面整体布局

页面顶部为空间统计概览卡片组，下方为空间管理主操作区（空间列表全宽表格 + 点击触发右侧抽屉详情）。

**统计概览卡片组**（4 张卡片横排）：

- 总空间数：平台内所有空间总数
- 个人空间：个人空间数量
- 工作空间：工作空间数量
- 专案空间：专案空间数量

每张卡片可点击，点击后自动按对应类型筛选下方空间列表，点击总空间数则清除筛选。

**空间管理主操作区**：

- 空间列表采用通栏表格形式展示
- 点击空间名称或操作列按钮后，通过右侧抽屉组件展示空间详情

#### 1.2 空间列表

**列表展示字段**：

| 列名      | 说明                                        |
| ------- | ----------------------------------------- |
| 空间名称    | 显示空间图标 + 空间名称 + 所属部门，名称可点击进入空间详情 |
| 所属警种/部门 | 空间归属的业务部门                                 |
| 空间类型    | 个人空间 / 工作空间 / 专案空间 |
| 成员数     | 当前空间成员总人数，支持排序 |
| 智能体数    | 已用智能体配额 / 智能体配额上限，支持排序 |
| 状态      | 启用 / 停用 / 归档 |
| 创建时间    | 空间创建日期，支持排序 |
| 操作      | 「编辑」「成员」按钮 + 「...」下拉菜单 |

**列表交互**：

- 支持按空间名称关键字模糊搜索
- 支持按状态（全部/启用/停用/归档）、空间类型（个人空间/工作空间/专案空间）下拉筛选
- 支持按创建时间、成员数、智能体数排序
- 支持分页浏览，默认每页 20 条
- 点击行选中空间并高亮
- **「创建空间」按钮**固定在列表顶部筛选栏右侧
- 「编辑」按钮点击直接进入详情抽屉的基本信息编辑模式
- 「成员」按钮点击进入详情抽屉的成员管理 Tab
- 「...」下拉菜单包含以下选项：

| 菜单项 | 说明 |
|------|------|
| 资源配额 | 打开详情抽屉并定位到资源配额 Tab |
| 停用/启用 | 根据空间当前状态动态切换，停用空间或恢复启用 |
| 归档 | 将空间归档，标记为历史终态 |
| 删除 | 删除空间（红色警示），二次确认后永久移除 |

#### 1.3 创建空间

点击「创建空间」按钮后，以**四步向导抽屉**承载创建流程。底部固定栏包含「取消」「上一步」「下一步/确认创建」按钮，第一步不显示「上一步」，第四步「下一步」变为「确认创建」。

**第一步：基本信息**

| 字段   | 类型    | 说明                  |
| ---- | ----- | ------------------- |
| 空间名称 | 文本输入  | 必填，校验全局唯一性          |
| 空间描述 | 文本域   | 选填                  |
| 空间图标 | 图标占位区 | 点击从预设图标库中选择或上传自定义图标 |
| 所属部门 | 下拉选择  | 必填，从组织架构中选择 |
| 空间类型 | 下拉选择  | 工作空间（默认）/ 专案空间 |

> 个人空间为平台默认开启，每个用户自动拥有个人空间，无需在此创建。

**第二步：预置资源**（可选步骤，支持跳过）

从平台组件管理已登记的资源中选择预置到该空间。七类资源分组展示，每组包括带图标的标题行和全宽多选下拉选择器，标题行右侧显示「已选 x 个」计数标签。

| 配置区 | 说明 |
|------|------|
| 模型 | 从已接入的模型列表中选择需预置的模型 |
| 提示词 | 从平台提示词库中选择需预置的提示词模板 |
| 工具 | 从可用工具清单中选择需预置的工具 |
| 连接器 | 从已注册的连接器中选择需预置的连接器 |
| 技能 | 从平台技能库中选择需预置的技能包 |
| 知识库 | 从系统知识库模板中选择需预置的知识库 |
| 数据连接 | 从已配置的数据连接中选择需预置的数据源 |

多选下拉选择器支持按资源名称关键字搜索，选中项以可移除标签形式展示在选择器内。

**第三步：资源配额**

创建时为空间设置初始配额上限，每项以数字输入框展示，默认填充平台统一默认值，可手动调整：

| 配额项 | 默认值 |
|------|------|
| 每日 Token 限额 | 200,000 Token/日 |
| 每月 Token 限额 | 5,000,000 Token/月 |
| 存储空间上限 | 5,000 MB |
| 智能体数量上限 | 10 个 |
| 成员数量上限 | 50 人 |

后续可在空间详情面板的资源配额 Tab 中修改。

**第四步：确认创建**

汇总展示本次创建的所有配置信息（基本信息摘要 + 预置资源清单），点击「确认创建」提交并关闭抽屉。

#### 1.4 空间详情抽屉

点击空间名称或操作列按钮后，右侧弹出抽屉组件展示空间详情。抽屉顶部显示空间头像、名称、类型标签和状态标签，下方以 Tab 切换展示以下内容：

**Tab 1：基本信息**

- 只读模式：展示空间名称、空间描述、所属部门、空间类型、创建人、创建时间、最近更新时间。底部提供「编辑」按钮。
- 编辑模式：切换为可编辑表单，包含空间名称（文本输入）、空间描述（文本域）、所属部门（下拉选择）、空间类型（只读输入框，不可修改）。底部提供「保存」「取消」按钮。

**Tab 2：成员管理**

- 个人空间：仅展示创建人名片，不可添加或修改成员，提示"个人空间仅创建人可访问"。
- 工作空间/专案空间：
  - 顶部操作栏：角色筛选下拉框（全部/创建人/管理员/普通用户）+ 成员搜索输入框 +「添加成员」按钮
  - 成员列表：头像 + 姓名 + 所属部门与加入时间 + 角色标签
  - 创建人角色只读，不可变更或移除
  - 非创建人成员：提供角色切换下拉框（管理员/普通用户）和「移除」按钮（二次确认后移除）
- 「添加成员」弹出对话框：
  - 选择成员：人员多选下拉组件，下拉选项展示头像、姓名、部门，支持按姓名/部门搜索
  - 初始角色：下拉选择（管理员/普通用户）

**Tab 3：资源配额**

- 配额概览：以进度条卡片形式展示五项配额使用情况（已用/总量 + 百分比进度条）：
  - 每日 Token 限额
  - 每月 Token 限额
  - 存储空间上限（MB）
  - 智能体数量上限
  - 成员数量上限
- 「设置配额」按钮：点击弹出设置对话框，包含五项配额的数字输入框，支持保存修改

**Tab 4：操作日志**

- 日志列表：操作时间、操作人、操作类型（以标签展示）、操作详情文本
- 仅展示，不可编辑或删除
- 支持分页浏览

#### 1.5 空间生命周期管理

空间在运维视角下受到三种管控操作：**停用**、**归档**、**删除**。三者面向不同场景，定位不可混淆。

**管控操作一览**：

| 操作 | 场景               | 行为                         |    可恢复    |
| -- | ---------------- | -------------------------- | :-------: |
| 停用 | 临时整改、风控审查、异常排查   | 空间不可进入、不可编辑；已发布智能体对外服务继续运行 |   随时恢复启用  |
| 归档 | 专案办结、部门裁撤、长期不活跃  | 空间不可进入、不可操作；已发布智能体对外服务停止   | 可恢复，不轻易操作 |
| 删除 | 误创建、从未启用、完全无效的空间 | 空间及数据永久移除，不可恢复             |    不可恢复   |

> **设计原则**：停用是"暂时关门"，归档是"使命完成，封存留档"，删除是"无效空间，直接清理"。从停用到归档是逐步升级的过程——先用停用观察，确认终局后再归档；从归档到删除是最终清洗。

**删除的条件**：

删除是不可逆操作，仅当满足以下所有条件时允许：

- 空间内无已发布或运行中的智能体
- 空间内无其他系统/智能体的外部调用依赖
- 二次确认：弹出确认对话框，用户需输入空间名称确认

典型场景：管理员创建了一个空间但从未启用就已废弃、测试空间构建后不再需要。

**空间状态**：

| 状态 | 说明        |
| -- | --------- |
| 启用 | 正常运行      |
| 停用 | 受管控，暂不可用  |
| 归档 | 历史封存，不再使用 |

> 删除的空间不再显示在列表中。操作列的「...」下拉菜单中根据空间当前状态动态切换「停用」/「启用」/「恢复」选项。归档状态的空间可通过「恢复」操作恢复为启用。列表筛选支持"全部/启用/停用/归档"四种状态维度。
