## 智能体测评需求设计

智能体测评是开发中心内对已构建智能体进行质量验证与性能评估的核心模块。通过结构化的评测任务管理、评测集数据建设与评估器定义，形成"选题 → 裁判 → 评测 → 分析"的闭环流程，帮助开发者量化衡量智能体在实际业务场景中的表现。

该模块位于开发中心左侧导航「智能体开发」菜单组下，菜单项名称为「智能体测评」。进入后以**页面内三级 Tab 导航**承载三个子视图：测评任务、数据集、评估器。各子 Tab 页面遵循平台通用的管理页面内容区结构（00_整体布局框架.md 3.5 节），顶部含统计数据指标卡片行，下方为列表型管理区域。

***

### 一、页面整体布局

智能体测评页面进入后默认展示「测评任务」Tab，顶部页面标题为「智能体测评」，标题右侧附带说明气泡提示（悬停展示功能简介）。标题栏下方为三级 Tab 导航：

| Tab     | 路由                    | 说明             |
| ------- | --------------------- | -------------- |
| 测评任务   | /evaluation/tasks     | 评测任务创建、执行与结果查看 |
| 数据集    | /evaluation/datasets  | 评测数据的采集、管理与版本发布 |
| 评估器    | /evaluation/evaluators | 评估规则的创建与维护     |

Tab 切换时刷新对应视图，筛选条件与分页状态不可跨 Tab 保持。

每个 Tab 页面均遵循通用管理列表页结构（00_整体布局框架.md 3.5 节）：

```
┌───────────────────────────────────────────────┐
│  数据指标卡片区（4 张横排统计卡片）                     │
├───────────────────────────────────────────────┤
│  筛选区（多条件筛选 + 搜索/重置按钮）  |  页面级操作按钮     │
├───────────────────────────────────────────────┤
│  数据展示区（表格列表，含状态 Tab 筛选）                  │
├───────────────────────────────────────────────┤
│  分页器                                          │
└───────────────────────────────────────────────┘
```

根据 00_整体布局框架.md 第四章交互容器分级，智能体测评模块使用以下容器：

| 容器   | 使用场景                          | 尺寸                        |

### 三、测评任务（Tab 1）

测评任务是评测模块的核心操作入口。开发者在此发起一次完整的评测执行——选定被评智能体、指定评测集与评估器，系统异步执行后产出综合评测报告。

#### 3.1 数据指标卡片区

| 卡片          | 说明                        | 交互     |
| ----------- | ------------------------- | ------ |
| 待执行任务数      | 状态为 pending 的任务数量         | 点击下钻过滤 |
| 执行中任务数      | 状态为 running 的任务数量         | 点击下钻过滤 |
| 已完成任务数      | 状态为 completed 的任务累计数量     | 点击下钻过滤 |
| 综合通过率       | 已完成任务中评测结果为 PASS 的占比（百分比） | 不可点击   |

点击前三张卡片后，下方列表自动筛选至对应状态 Tab 并展示结果。

#### 3.2 筛选区

| 筛选项      | 类型      | 说明                   |
| -------- | ------- | -------------------- |
| 任务名称     | 文本输入    | 模糊匹配，支持关键字搜索         |
| 智能体      | 下拉选择    | 从当前空间已发布智能体列表中选择     |
| 评测集      | 下拉选择    | 从当前空间已发布评测集列表中选择     |
| 状态       | 下拉多选    | 待执行/执行中/已完成/失败，默认全部  |
| 创建时间     | 日期范围选择器 | 支持自定义时间区间筛选          |
| 「查询」按钮   | —       | 执行筛选                 |
| 「重置」按钮   | —       | 清空所有筛选条件，恢复默认        |

页面级操作区：右侧「创建评测任务」按钮（蓝色高亮主按钮）。

#### 3.3 任务列表

列表上方内嵌状态 Tab 导航：全部 / 执行中 / 已完成 / 失败，切换时过滤列表数据，保持当前筛选条件。

**列表展示字段**：

| 列名    | 说明                                                                     |
| ----- | ---------------------------------------------------------------------- |
| 任务名称  | 可点击链接，点击打开任务详情抽屉                                                      |
| 状态    | 标签样式：待执行（灰色）/ 执行中（蓝色动态）/ 已完成（绿色）/ 失败（红色）                             |
| 任务结果  | 已完成时展示综合评分（如 4.8 / 5.0），通过/未通过标识；非完成状态显示"–"                            |
| 智能体   | 被评测的智能体名称，可点击跳转至该智能体配置页                                               |
| 评测集   | 使用的评测集名称及版本号                                                           |
| 评估器   | 参与评价的评估器列表（多个以逗号分隔，悬停可查看完整列表及各自权重）                                     |
| 完成时间  | 任务完成的精确时间，非完成状态显示"–"                                                   |
| 操作    | 已完成：「详情」「重新评测」「删除」；执行中：「详情」「终止」「删除」；待执行：「详情」「执行」「删除」；失败：「详情」「重新评测」「删除」 |

**任务列表交互行为**：

- 「重新评测」：使用与原任务完全相同的配置（智能体、评测集、评估器）重新发起一个全新任务，评测集默认使用其当前最新发布版本
- 「终止」：仅对执行中状态可用，点击弹出确认弹窗，确认后立即终止任务并将状态标为"失败"
- 「删除」：任意状态可点击，弹出确认弹窗后删除任务及关联结果数据，不可恢复
- 列表支持分页，默认每页 10 条

#### 3.4 创建评测任务

点击「创建评测任务」按钮，右侧滑出创建抽屉（宽度约 55%），组织为两步流程。

**第一步 — 基本信息**：

| 字段   | 类型   | 说明                           |
| ---- | ---- | ---------------------------- |
| 任务名称 | 文本输入 | 必填，最大 100 字符                 |
| 描述   | 文本域  | 选填，补充说明评测目的、范围和特殊要求          |

**第二步 — 评测配置**：

| 字段       | 类型       | 说明                                                               |
| -------- | -------- | ---------------------------------------------------------------- |
| 待评测智能体   | 下拉单选     | 必填。从当前空间已发布状态的智能体列表中选择，仅展示已通过发布校验的智能体（若存在草稿未发布的修改则提示"该智能体当前存在未发布的配置变更"） |
| 选择评测集    | 下拉单选 + 版本选择 | 必填。先选评测集，再选该评测集下的已发布版本。默认选中最新发布版本                                 |
| 选择评估器    | 下拉多选     | 必填，至少选 1 个。从当前空间已创建的评估器列表中选择                                   |
| 评估器权重分配  | 数值输入组    | 当选中的评估器 > 1 时出现。每个评估器配置一个 0-100 的整数权重，总和须等于 100%。实时显示当前权重总和与合规状态    |
| 执行策略     | 单选       | 立即执行（默认）/ 定时执行。选择定时执行时展开日期时间选择器                                  |

底部操作栏：「取消」（关闭抽屉，有未保存内容时弹出确认）++「确认执行」（校验后异步提交任务）。

提交成功后 Toast 提示"评测任务创建成功，已加入执行队列"，关闭抽屉，列表自动刷新。

#### 3.5 任务详情与评测报告

点击任务名称或操作列的「详情」按钮，右侧滑出任务详情抽屉（宽度约 55%）。

**抽屉顶部固定区**：

- 左侧：任务名称 + PASS/FAIL 状态标签（已完成时显示）
- 右侧：综合评分大数值（如 4.8 / 5.0，已完成时显示）
- 下方：执行时间、完成时间、执行人、受测智能体（可点击跳转）、题库评测集（含版本号）、参与评估裁判（评估器列表）

**抽屉内容 Tab**：

| Tab    | 说明                                   |
| ------ | ------------------------------------ |
| 统计指标  | 任务级汇总统计，各评估器维度的得分分布                  |
| 评测明细  | 逐条数据项的评测详情列表，按通过/未通过分类筛选             |

**Tab 1：统计指标**

- **指标卡片行**（4 张横排）：总体平均分、用例通过率、严重失败用例数（评分为最低分的用例数量）、平均生成延时（ms）
- **各评估器维度得分分布**：以进度条卡片展示每个评估器的得分（满分 5.0）+ 各自权重占比，进度条颜色按得分高低变化（绿色 ≥ 4.0，蓝色 3.0-3.9，红色 < 3.0）

**Tab 2：评测明细**

- **分类筛选条**：按钮组切换全部用例 / 未通过用例 / 已通过用例，每组附带用例数量角标
- **搜索框**：支持按 Query 内容关键词搜索
- **明细列表**：

| 列名    | 说明                                      |
| ----- | --------------------------------------- |
| 状态    | 通过/未通过图标（绿色勾/红色叉）                       |
| 输入内容  | 评测数据项中的输入字段内容（如 user_query），可展开查看完整文本    |
| 期望输出  | 评测数据项的参考输出，可展开查看完整文本                    |
| 实际输出  | 智能体实际生成的回复，可展开查看完整文本，与期望输出对比高亮差异        |
| 综合评分  | 该用例的综合得分（满分 5.0），通过标注为绿色，未通过与低分标注为红色     |
| 各评估器分 | 以 Tag 横排展示各评估器对该用例的独立评分，悬停显示评测理由摘要       |
| 延时    | 该条用例的生成耗时（ms）                           |

- 列表支持分页，默认每页 20 条
- 支持导出当前筛选结果为 CSV/Excel（右上角「导出」按钮）

#### 3.6 通用交互行为

- 任务创建后为异步执行模式，状态从"待执行" → "执行中" → "已完成/失败"，页面可通过手动刷新查看最新状态
- 所有删除操作需二次确认，确认后立刻移除任务及相关结果数据
- 重新评测操作基于最新评测集版本创建新任务，原任务不受影响
- 评测明细中的导出操作尊重当前筛选条件，仅导出筛选后的可见数据

### 四、数据集（Tab 2）

数据集是评测模块的数据底座，存储用于评测智能体的标准输入与期望输出数据对。每条数据集支持版本化管理，评测任务通过引用特定版本的评测集保证评测结果的可复现性。

#### 4.1 数据指标卡片区

| 卡片      | 说明                | 交互     |
| ------- | ----------------- | ------ |
| 评测集总数   | 当前空间内评测集的总数量      | 不可点击   |
| 含草稿评测集  | 存在未发布草稿版本的评测集数量   | 点击下钻过滤 |
| 总数据条数   | 所有评测集的累计数据条目数（去版本） | 不可点击   |
| 本周新增评测集 | 本周内创建的评测集数量       | 不可点击   |

#### 4.2 筛选区

| 筛选项       | 类型   | 说明                        |
| --------- | ---- | ------------------------- |
| 评测集名称     | 文本输入 | 模糊匹配                      |
| 来源类型      | 下拉单速 | 全部/自动生成/手动导入/混合组装         |
| 「查询」按钮    | —    | 执行筛选                      |
| 「重置」按钮    | —    | 清空筛选条件，恢复默认               |

页面级操作区：「创建评测集」按钮（主按钮）+「从资源广场导入」按钮（默认置灰，功能预留）。

#### 4.3 评测集列表

**列表展示字段**：

| 列名        | 说明                                                        |
| --------- | --------------------------------------------------------- |
| 评测集名称     | 评测集名称，加粗展示                                                |
| 来源类型      | 标签：自动生成（紫色）/ 手动导入（青色）/ 混合组装（蓝灰）                          |
| 数据量       | 当前发布版本的数据条目数（等宽数字展示）                                      |
| 当前发布版本    | 发布版本号（绿色标签）+ 是否含草稿标识（橙色标签"含草稿"，仅存在未发布变更时展示）                 |
| 管理者       | 评测集创建人或当前负责人                                             |
| 创建时间      | 创建日期时间                                                    |
| 操作        | 「管理」（进入数据管理抽屉）「历史」（查看版本历史）「删除」（删除确认弹窗），操作列固定在表格右侧为固定列      |

#### 4.4 创建评测集

点击「创建评测集」按钮，右侧滑出创建抽屉（宽度约 50%），分三步完成。

**第一步 — 基本信息**：

| 字段   | 类型        | 说明                          |
| ---- | --------- | --------------------------- |
| 名称   | 文本输入      | 必填，最大 50 字符，校验当前空间内唯一性       |
| 描述   | 文本域       | 选填，描述评测集的用途和覆盖场景            |
| 来源类型 | 单选卡片组     | 手动导入 / 自动生成 / 混合组装，三选一      |
| 是否立即发布 | 开关        | 开启时创建后自动发布 v1.0 版本，关闭时仅保存为草稿 |

**第二步 — 数据录入**（根据来源类型不同展示不同界面）：

**手动导入模式**：

- 提供表格表单，每行为一条评测数据
- 每条数据包含：录入问题（必填，文本输入）、录入背景/上下文（选填，文本输入）、期望输出（必填，文本域）
- 「添加一行」按钮动态追加空行
- 每行右侧「移除」按钮删除该行
- 也支持通过 CSV/JSON 文件批量导入，点击「上传文件」按钮选择文件，系统解析后自动填入表格

**自动生成模式**：

- 通过 AI 辅助批量生成评测数据
- 用户输入主题描述（如"电诈案件中的典型用户问询场景"），选择数据生成条数（10/50/100/自定义）
- 系统调用大模型生成多样化的用户输入 + 期望输出配对
- 生成结果以表格预览展示，用户可逐条编辑、删除或重新生成

**混合组装模式**：

- 同时存在手动录入和自动生成的数据
- 页面上方为手动导入表格区域，下方为 AI 批量生成区域
- 两种来源的数据合并展示在同一个预览表格中

**第三步 — 确认保存**：

- 汇总展示评测集名称、来源类型、数据条数、是否立即发布等信息
- 点击「确认创建」提交，保存成功后根据"是否立即发布"开关决定：
  - 开启：自动发布版本 v1.0，Toast 提示"评测集初始版本 v1.0 发布成功"
  - 关闭：仅保存草稿，Toast 提示"评测集草稿创建成功，请进入数据管理补充或核对数据后发布版本"

#### 4.5 数据管理

点击列表操作列的「管理」按钮，右侧滑出数据管理抽屉（宽度约 55%）。抽屉顶部展示当前评测集名称与当前发布版本号。

**抽屉内部布局**：

- **Tab 切换**：数据管理与历史版本两个 Tab
- **数据管理 Tab**：
  - 以表格形式展示评测集中的全部数据条目
  - 列：录入问题（user_query）、录入背景（context，可选）、期望输出（reference output）、编辑、移除
  - 支持逐条在线编辑和逐条移除
  - 顶部提供「添加数据」按钮（追加空白行或上传文件）和「AI 批量生成」按钮
  - 当数据发生增删改后，当前版本号后显示橙色"含未发布变更"标签
  - 数据变更后底部出现「发布新版本」按钮，点击进入版本发布流程

**版本发布流程**：

- 点击「发布新版本」弹出发布确认弹窗
- 弹窗内容：当前数据变更统计（新增 X 条 / 修改 Y 条 / 删除 Z 条）、版本号自动递增（如 v1.2 → v1.3）、版本变更说明（选填文本域）
- 确认发布后 Toast 提示"新版本发布成功"，版本号更新，草稿标识消失

#### 4.6 历史版本

点击列表操作列的「历史」按钮或在数据管理抽屉中切换到「历史版本」Tab，浏览评测集的版本演变记录。

**版本列表**：

| 列名    | 说明                          |
| ----- | --------------------------- |
| 版本号   | v1.0, v1.1, v1.2…          |
| 数据量   | 该版本包含的数据条目数                |
| 变更说明  | 发布时填写的版本说明                 |
| 发布人   | 执行发布操作的用户                  |
| 发布时间  | 精确到秒                        |
| 状态    | 当前版本（绿色标签）/ 历史版本（灰色标签）     |

- 点击版本号可预览该版本下的数据内容（只读表格，不可编辑）
- 历史版本不可删除，仅当前最新发布版本可被评测任务引用

#### 4.7 通用交互行为

- 删除操作需二次确认，删除评测集会同时删除所有关联版本数据，已在评测任务中引用该评测集的历史任务不受影响（评测集版本数据独立快照）
- 「从资源广场导入」功能预留给资源广场模块对接，当前置灰禁用
- 列表刷新按钮与列设置按钮位于列表右上角操作工具栏，与通用管理页布局一致

### 五、评估器（Tab 3）

评估器是评测模块的裁判规则单元，定义了如何对智能体的输出进行量化打分。支持两种评估器类型：基于 LLM 评判的评估器和基于代码逻辑的评估器（Code 类暂未实现）。

#### 5.1 数据指标卡片区

| 卡片     | 说明               | 交互   |
| ------ | ---------------- | ---- |
| 评估器总数  | 当前空间内已创建的评估器数量   | 不可点击 |
| LLM 类  | LLM 类型评估器数量      | 不可点击 |
| Code 类 | Code 类型评估器数量     | 不可点击 |
| 累计使用   | 所有评估器被评测任务引用的总次数 | 不可点击 |

| 筛选项       | 类型   | 说明                 |

| 创建时间      | 日期范围 | 筛选指定时间区间内创建的评估器    |
| 「查询」按钮    | —    | 执行筛选               |

#### 5.3 评估器列表

**列表展示字段**：

| 列名    | 说明                                  |

#### 5.4 创建/编辑评估器

点击「创建评估器」按钮或列表中的「编辑」按钮，右侧滑出创建/编辑抽屉（宽度约 60%），分四个区块组织配置。

**一、评估器类型与基本设定**：

| 字段    | 类型   | 说明                   |
| ------ | ---- | -------------------- |
| 评估器名称  | 文本输入 | 必填                   |
| 评估器描述  | 文本域  | 选填，一句话描述评估器的评判维度和作用  |
| 创建方式   | 单选卡片 | LLM / Code，二选一       |

**LLM 类型**（当前可用）：

通过 Prompt 设计规则，让大模型判断预期输出和实际输出之间的差异。

**Code 类型**（当前不可用，占位展示）：

通过编写代码函数来执行确定性对比逻辑（如字符串匹配、正则验证、数值比较等）。页面中央显示"功能正在开发中，敬请期待"的占位提示，确认创建按钮置灰。

**二、模型配置与评测标准**（仅 LLM 类型）：

| 字段       | 类型        | 说明                                            |
| -------- | --------- | --------------------------------------------- |
| 选择模型     | 下拉单选      | 必填，从已接入的模型列表中选择，默认推荐 Qwen-Max                |
| 温度(Temperature) | 滑块   | 范围 0-1，步长 0.1，默认 0.3                         |
| Top-P    | 滑块        | 范围 0-1，步长 0.1，默认 0.8                         |
| Prompt   | 富文本输入     | 必填。评估指令，包含评判标准和输出格式要求。预设模板变量提示行（query, context, reference, response 四个运行时注入变量） |
| AI 智能优化 | 功能按钮      | 点击后调用 AI 辅助优化当前 Prompt 文本，使其更规范、评判维度更清晰      |

**Prompt 预设变量说明**：

| 变量        | 说明             |
| --------- | -------------- |
| `query`   | 评测数据项中的用户输入内容  |
| `context` | 评测数据项中的上下文背景信息 |
| `reference` | 评测数据项中的期望输出    |
| `response` | 智能体实际生成的回复     |

系统要求评估 Prompt 以 JSON 格式输出评估结果，至少包含 `score` 字段。示例输出格式：`{score: 5, reason: '准确且简洁。'}`。

**三、评分解析阈值**：

| 字段    | 类型   | 说明                                     |
| ----- | ---- | -------------------------------------- |
| 评分范围  | 数值区组 | 设定评分的最小值和最大值（如 1-5），中间以"–"连接         |
| 通过阈值  | 数值输入 | 设定判定"通过（PASS）"的最低分数，默认 3              |
| 超时阈值  | 数值输入 | 评估器单条数据最长执行时间（秒），超时标记为异常              |

设定评分范围和通过阈值后，系统可自动判定每条评测结果是否通过，形成可量化的统计闭环。

**四、测试验证（可选）**：

提供一组示例输入/期望输出，用户可输入智能体实际输出并「运行测试」，实时查看评估器返回的评分结果和评判理由，验证评估器的有效性和公正性。

底部操作栏：「取消」（关闭抽屉，有未保存内容时弹出确认）+「确认创建」/「保存修改」。

#### 5.5 通用交互行为

- 编辑评估器配置后，使用该评估器的历史评测任务中的旧版本评估器结果不受影响（历史快照机制），新创建的评测任务将使用更新后的评估器配置
- 删除评估器需二次确认，若该评估器已被评测任务引用则额外提示"该评估器已被 X 个评测任务引用，删除后将影响历史任务的结果可读性"，确认后删除
- 列表刷新按钮与列设置按钮位于列表右上角操作工具栏

### 六、跨模块联动

智能体测评模块与平台其他模块存在以下联动关系：

| 关联模块   | 联动方式                                                |
| ------ | --------------------------------------------------- |
| 智能体构建   | 评测任务的"待评测智能体"下拉列表数据来源于智能体管理中已发布的智能体；点击任务详情中的智能体名称可跳转至该智能体配置页 |
| 模型管理   | 评估器创建时的模型选择列表来源于已接入的模型；评估器执行时调用对应模型的推理能力            |
| 知识库管理   | 自动生成的评测数据可基于关联知识库的主题生成场景化的问答对（预留功能）                 |
| 资源广场   | 「从资源广场导入」按钮预留给评测集和评估器从广场引入共享资源（当前置灰，功能预留）           |
