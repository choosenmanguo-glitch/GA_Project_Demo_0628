### 六、智能体监控详情页

智能体监控详情页是智能体的专属运维视图，从运维中心的智能体分析、运营洞察、会话日志等页面中点击任一智能体名称后，以**右侧抽屉面板**形式打开，无需离开当前页面即可查看该智能体的基础信息、运行数据和使用记录。页面内容分为三个 Tab。

#### 6.1 页面布局

- 打开方式：右侧滑出抽屉面板（宽度约占屏幕 50%）
- 顶部固定：智能体名称 + 头像 + 状态标签（已发布/已下架/草稿）+ 所属空间 +「在新窗口打开」按钮
- Tab 切换栏：概览 / 使用统计 / 使用日志

#### 6.2 Tab 1：概览

展示该智能体的基础属性信息。

**基本信息**：

- 智能体名称、图标、类型（标准/流程/自主）
- 所属空间（可点击跳转至空间详情）
- 状态（已发布/已下架/草稿）
- 描述文本
- 创建人、创建时间、最近发布时间

**关联资源清单**（以只读标签列表展示）：

- 关联模型：列出该智能体绑定的模型名称（多个以标签形式横排）
- 关联知识库：列出该智能体挂载的知识库名称（可点击跳转）
- 挂载工具：列出该智能体已配置的工具数量及名称标签

#### 6.3 Tab 2：使用统计

展示该智能体的核心运行指标与趋势，复用运维中心智能体分析（2.1 节）的图表能力。

**指标卡片行**（4 张横排）：

- 累计使用次数：智能体被调用的总次数
- 活跃用户数：近三十天使用过该智能体的去重用户数
- Token 总消耗：该智能体运行累计 Token 消耗量
- 平均运行成功率：成功完成次数占总调用次数的比例

**图表区**（默认展示近三十天数据，支持切换时间范围）：

| 图表         | 类型  | 说明                            |
| ---------- | --- | ----------------------------- |
| 使用次数趋势     | 面积图 | 按日展示该智能体调用次数变化                |
| 使用渠道分布     | 环形图 | Web端 / API / 企微 / 第三方 各渠道调用占比 |
| Token 消耗趋势 | 折线图 | 按日展示 Token 输入/输出消耗变化          |
| 用户反馈统计     | 柱状图 | 点赞数 + 点踩数 按日对比                |
| 响应耗时趋势     | 折线图 | P50 / P95 / P99 响应耗时（ms）变化    |
| 活跃用户趋势     | 折线图 | 按日展示使用该智能体的活跃用户数变化            |

#### 6.4 Tab 3：使用日志

展示该智能体下所有会话的汇总列表，与运维中心"会话日志"模块共享同一数据源，但默认筛选范围为当前智能体。

- 会话列表字段与会话日志模块一致（会话 ID、渠道、使用者、消息数、Token 消耗、开始时间、最后活跃、状态）
- 支持按时间范围、使用渠道、状态筛选
- 点击行展开对话明细（使用会话日志模块 5.4 的相同交互）
- 列表支持导出为 Excel

#### 6.5 通用交互行为

- 抽屉面板从右侧滑出，背景页面半透明遮罩
- 面板支持独立滚动，不影响背景页面浏览
- 点击面板外区域或右上角关闭按钮关闭抽屉
- 「在新窗口打开」按钮将当前监控视图在独立浏览器标签页中打开，适用于需要同时查看多个智能体的运维场景
- 面板内筛选条件（时间范围等）仅影响当前 Tab 数据，关闭后面板恢复默认状态
