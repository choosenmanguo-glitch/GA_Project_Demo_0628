## 导航体系

平台导航采用三级结构：一级导航（顶栏固定）→ 菜单组（左侧导航灰色分组标签）→ 菜单项（左侧导航可点击菜单）。部分菜单项下设有三级 Tab 导航（页面内水平切换），不在左侧导航中展开。

### 开发中心

开发中心是空间内用户进行智能体全生命周期管理的核心工作区。顶部嵌入「工作空间切换器」展示当前进入的空间。

| 菜单组    | 菜单项   | 说明                          | 三级菜单（若有）       |
| ------ | ----- | --------------------------- | :------------- |
| <br /> | 工作台   | 工作台（独立菜单，进入开发中心后的默认首页）      | <br />         |
| 智能体开发  | 智能体构建 | 可视化编排画布，搭建智能体流程             | <br />         |
| <br /> | 智能体管理 | 智能体列表、版本管理与发布               | <br />         |
| <br /> | 智能体测评 | 页面内 Tab 切换：测评任务 / 测评集 / 评估器 | <br />         |
| 资源广场   | 资源广场  | 浏览和应用平台共享资源                 | <br />         |
| <br /> | 我的资源  | 管理个人上传或收藏的资源                | <br />         |
| 组件管理   | 模型    | 模型接入与配置                     | <br />         |
| <br /> | 提示词   | 提示词模板管理                     | <br />         |
| <br /> | 工具    | 工具组件注册与管理                   | 插件工具/API工具/工作流 |
| <br /> | 连接器   | MCP 服务与其他外部连接器配置            | <br />         |
| <br /> | 技能    | 可复用技能单元管理                   | <br />         |
| <br /> | 数据链接  | 数据源连接配置                     | <br />         |
| <br /> | 知识库   | 知识库创建、文档管理与检索配置             | <br />         |
| 空间运营   | 统计分析  | 当前空间运营数据仪表盘                 | <br />         |
| <br /> | 空间管理  | 当前空间的基本信息、成员、日志与高级操作        | <br />         |

### 运维中心

运维中心面向平台超级管理员，提供组织级空间统管与全平台运营运维能力。

| 菜单组    | 菜单项   | 说明                        | 三级菜单（若有）    |
| ------ | ----- | ------------------------- | :---------- |
| 空间管理   | 空间管理  | 平台全部工作空间的创建、编辑、启停、配额与模板管理 | <br />      |
| 资源监控   | 智能体分析 | 全平台智能体运行指标监控              | <br />      |
| <br /> | 模型分析  | 模型调用量、成功率、延迟等指标分析         | <br />      |
| <br /> | 知识库分析 | 知识库检索命中率、文档规模等分析          | <br />      |
| <br /> | 工具分析  | 工具调用频率、成功率等分析             | <br />      |
| <br /> | 连接器分析 | 连接器/MCP 服务健康状态分析          | <br />      |
| 运营洞察   | 部门分析  | <br />                    | <br />      |
| <br /> | 用户分析  | <br />                    | <br />      |
| <br /> | 空间分析  | <br />                    | <br />      |
| 运维监控   | 告警监控  | <br />                    | 告警记录 / 告警规则 |
| <br /> | 会话日志  | 全平台智能体会话日志检索与明细查看         | <br />      |

### 管理中心

管理中心暂不细化，预留给系统级配置管理（组织管理、用户管理、角色岗位管理等）。
