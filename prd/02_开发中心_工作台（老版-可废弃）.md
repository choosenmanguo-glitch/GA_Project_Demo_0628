## 工作台需求设计

工作台是进入开发中心后的默认首页，定位于"空间门户"，帮助用户快速感知当前空间状态、了解标准化开发流程，并提供核心数据概览、最近项目、待办消息和各功能模块的快捷入口。页面面向空间内所有角色（普通用户和管理员）开放。

---

### 一、页面布局

工作台自上而下分为六个区域：

- **欢迎区**：当前空间信息 + 问候语 + 平台实时状态指标
- **开发流程区**：标准化智能体上线链路（5步） + 总体进度指示
- **数据指标区**：5张核心指标卡片，其中调用量卡片包含日趋势微折线图
- **最近智能体与待办区**：左侧最近智能体列表 + 右侧待办与消息
- **快捷入口区**：8个功能模块的卡片式入口 + 空间管理入口

---

### 二、欢迎区

页面顶部展示当前空间的核心信息与平台实时状态。

#### 2.1 空间信息行

| 元素 | 说明 |
|---|---|
| 空间头像 | 显示空间首字母，渐变蓝色背景 |
| 空间名称 | 加粗显示 |
| 可信空间标签 | 带安全认证图标的绿色标签 |
| 空间副标题 | "N 位成员 · 所属部门 · 今日 HH:MM 活跃" |
| 空间切换器 | 行内按钮，可快速切换到其他已加入的空间 |

#### 2.2 问候语与平台状态

| 元素 | 说明 |
|---|---|
| 问候语 | "欢迎回来，[用户名]" |
| 引导文案 | "按照搭建、接入、配置、测评、发布的链路推进智能体上线。" |
| 平台实时状态面板 | 三栏指标：今日智能体调用次数、活跃用户数、服务状态（正常/异常），各栏之间以竖线分隔 |

---

### 三、开发流程区

为开发者提供标准化的智能体上线路径指引，展示当前整体进度。

#### 3.1 区域头部

| 元素 | 说明 |
|---|---|
| 小标题 | "开发流程" |
| 主标题 | "智能体上线链路" |
| 进度条 | 显示总体完成百分比（如 60%） |

#### 3.2 流程步骤卡片（5张）

| 步骤 | 标题 | 描述 | 状态标签 | 点击行为 |
|---|---|---|---|---|
| 1 | 搭建智能体 | 创建对话、流程或自主智能体 | 已开放 | 跳转智能体构建 |
| 2 | 接入知识与数据 | 挂接知识库、数据源和资源 | 推荐 | 跳转知识库 |
| 3 | 配置模型与工具 | 选择模型、工具与连接器能力 | 常用 | 跳转模型管理 |
| 4 | 测评验证 | 使用评测集验证效果与稳定性 | 待完善 | 跳转智能体测评 |
| 5 | 发布上线 | 完成审核后发布至服务门户 | 规范化 | 跳转智能体管理 |

每张卡片包含：步骤序号（大号数字水印）、图标、步骤标题、状态标签、功能描述、右箭头指示器。点击卡片跳转至对应功能页面。

---

### 四、数据指标区

以一行 5 张指标卡片展示当前空间的核心数据，部分数据随空间切换联动刷新。

| 卡片 | 数值 | 次级说明 | 特殊元素 | 点击行为 |
|---|---|---|---|---|
| 我的智能体 | 用户创建数 | 已发布 N 个 | - | 跳转智能体管理 |
| 空间智能体 | 空间总数 | 已发布 N / 总数 N | - | 跳转智能体管理 |
| 近七天调用量 | 总计次数 | 今日 N 次 | 底部 7 日调用趋势面积图 | 跳转统计分析 |
| 知识库文档 | 累计篇数 | 本周新增 N 篇 | - | 跳转知识库 |
| 我的待办 | 待办项数 | 测评与发布任务 | - | 跳转智能体测评 |

每张卡片为独立卡片样式，包含标题、图标、数值（含单位）、次级说明文字。卡片整体可点击，悬停有抬起效果。

---

### 五、最近智能体与待办

采用左右双栏布局。

#### 5.1 最近智能体 / 我的项目（左侧，占 2/3 宽）

以列表形式展示用户最近操作或关注的智能体。

| 显示元素 | 说明 |
|---|---|
| 智能体图标 | 圆形机器人图标 |
| 智能体名称 | 加粗显示 |
| 状态标签 | 已发布（绿色）/ 草稿（黄色） |
| 类型标签 | 标准智能体 / 流程智能体 等 |
| 更新时间 | 格式 YYYY-MM-DD |
| 调用次数 | 数字 |
| 操作按钮 | 文案根据智能体状态动态变化（查看运行 / 配置流程 / 继续编辑 等），点击跳转智能体管理 |

卡片标题行右侧提供「查看全部」链接，跳转至智能体管理。

#### 5.2 待办与消息（右侧，占 1/3 宽）

以列表形式展示当前用户待处理的任务与系统提醒。

| 元素 | 说明 |
|---|---|
| 待办图标 | 彩色圆形图标，每个待办项不同颜色 |
| 待办标题 | 加粗显示 |
| 待办描述 | 灰色辅助文字 |
| 待办数量角标 | 卡片标题行显示待办总数角标 |

待办项类型包含：

| 待办项 | 描述示例 |
|---|---|
| 评测任务待处理 | N 个智能体等待回归评测 |
| 发布审核 | N 个智能体待确认上线范围 |
| 模型配置提醒 | 某模型有新配置项 |
| 资源申请进度 | 某接口审批中 |

点击待办项跳转至对应处理页面。

---

### 六、快捷入口区

以卡片网格形式展示开发中心各模块的快捷入口。区域头部含「空间管理」链接（管理员可见）。

#### 6.1 快捷入口卡片（8 张）

| 卡片 | 功能描述 | 特殊标记 | 点击跳转 |
|---|---|---|---|
| 智能体构建 | 可视化编排智能体流程 | - | 智能体构建 |
| 智能体管理 | 查看和管理已创建的智能体 | 数量角标 | 智能体管理 |
| 模型管理 | 接入和配置大模型 | - | 模型管理 |
| 提示词管理 | 管理可复用的提示词模板 | - | 提示词管理 |
| 工具管理 | 注册和管理工具组件 | - | 工具管理 |
| 连接器 | 配置 MCP 服务与外部连接器 | - | 连接器管理 |
| 知识库 | 创建知识库、上传文档 | - | 知识库 |
| 智能体测评 | 对智能体进行效果评估 | - | 智能体测评 |

每张卡片包含：彩色图标、模块名称（含可选角标）、一行功能简述、右箭头。点击跳转至对应功能页面。

#### 6.2 空间管理入口

快捷入口区标题行右侧显示「空间管理」链接按钮（仅管理员可见），点击跳转至空间运营页面。

---

### 七、通用交互行为

- 工作台所有数据（空间智能体数等）随空间切换器联动刷新
- 数据指标区卡片、开发流程卡片、快捷入口卡片、待办项均为可点击热区，悬停有轻微上浮效果（边框变色 + 阴影加深）
- 页面不设分页器，所有内容单屏友好展示

### 八、响应式适配

| 断点 | 适配行为 |
|---|---|
| ≤ 1180px | 容器宽度收窄；欢迎区问候语与状态面板纵向排列；状态面板撑满宽度；开发流程卡片、数据指标卡片、快捷入口卡片由单行变为 2 列 |
| ≤ 720px | 容器进一步收窄；状态面板变为单列纵向排列（分隔线隐藏）；开发流程卡片、数据指标卡片、快捷入口卡片均由 2 列变为 1 列；进度条隐藏 |
