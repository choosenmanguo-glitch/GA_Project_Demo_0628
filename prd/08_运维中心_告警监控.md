### 四、告警监控

告警监控提供平台运行过程中各类告警事件的实时监控与集中处理能力，覆盖智能体、模型、API、连接器、知识库等资源的异常告警，帮助运维人员快速发现并处置生产环境问题。

页面顶部为 Tab 导航栏，包含「告警记录」和「告警规则」两个 Tab，默认展示告警记录页。

***

#### 4.1 Tab 1：告警记录

##### 4.1.1 页面布局

- 顶部：告警统计概览卡片组（4 张）
- 中部：筛选栏（时间范围 + 级别 + 类型 + 状态 + 空间 + 关键字搜索）
- 下方：告警列表（表格形式，占主体区域）
- 右侧：选中告警的详情抽屉面板（点击某条告警后从右侧滑出）

##### 4.1.2 告警统计卡片组

| 卡片    | 说明                     |
| ----- | ---------------------- |
| 当前未处理 | 红色高亮，显示当前状态为"待处理"的告警总数 |
| 处理中   | 橙色，显示状态为"处理中"的告警数      |
| 今日已解决 | 绿色，显示今日已关闭的告警数         |
| 今日新增  | 蓝色，显示今日新产生的告警数         |

每张卡片可点击，点击后自动筛选下方列表中对应状态的告警。

##### 4.1.3 告警列表

**列表展示字段**：

| 列名   | 说明                                                 |
| ---- | -------------------------------------------------- |
| 级别   | 严重程度标签：紧急（红色）/ 严重（橙色）/ 警告（黄色）/ 提示（蓝色）              |
| 告警标题 | 告警摘要标题，点击打开右侧详情抽屉                                  |
| 告警类型 | 智能体异常 / 模型调用失败 / API 超时 / 连接器中断 / 知识库检索异常 / 配额超限 等 |
| 关联资源 | 出问题的具体资源名称（如"刑侦知识库问答智能体""GPT-4o 模型"），可点击跳转         |
| 所属空间 | 发生告警的空间名称，可点击跳转                                    |
| 发生时间 | 告警首次触发时间                                           |
| 持续时间 | 从首次触发到当前的时间长度                                      |
| 状态   | 待处理 / 处理中 / 已解决                                    |
| 操作   | 「认领」「解决」「忽略」按钮组                                    |

**列表交互**：

- 默认按级别优先（紧急>严重>警告>提示）、发生时间倒序排列
- 支持按级别、告警类型、状态、空间、时间范围组合筛选
- 支持按告警标题关键字搜索
- 支持分页浏览，默认每页 20 条
- 新告警到达时列表顶部出现「有 N 条新告警」提示横幅，点击刷新列表

##### 4.1.4 告警详情抽屉

点击告警行，右侧滑出详情抽屉面板（宽约 45%），包含以下内容区域：

**基本信息区**：

- 告警标题、级别标签、当前状态、发生时间、持续时长
- 关联资源名称（可点击跳转至开发中心对应资源的管理页）
- 所属空间（可点击跳转至空间详情面板，见第一节 1.4）

**告警详情区**：

- 告警描述：自然语言描述告警的具体内容
- 触发条件：触发该告警的阈值规则说明
- 错误详情：原始错误信息/堆栈（可展开收起）
- 建议处理方案：系统推荐的处理步骤列表

**历史轨迹区**：

- 该告警的处理操作时间线（创建 → 认领 → 处理中 → 已解决），以纵向步骤条展示
- 每条记录包含：操作人、操作类型、操作时间、备注说明

**操作按钮区**（面板底部固定）：

- 「认领」：将告警状态从"待处理"改为"处理中"，记录认领人
- 「解决」：弹出解决确认框，填写处理备注后关闭告警，状态变为"已解决"
- 「忽略」：弹出忽略确认框，填写忽略原因后关闭告警，标记为"已忽略"
- 「创建工单」：一键创建关联运维工单（如对接外部工单系统）

#### 4.2 Tab 2：告警规则

告警规则页以表格形式展示所有已配置的告警规则，顶部提供「新建规则」按钮。

##### 4.2.1 页面布局

- 顶部：「新建规则」按钮（右对齐）
- 下方：规则列表表格

##### 4.2.2 规则列表

| 列名   | 说明                                         |
| ---- | ------------------------------------------ |
| 规则名称 | 规则标识名称                                     |
| 监控对象 | 智能体运行 / 模型调用 / API 响应 / 连接器 / 知识库检索 / 资源配额 |
| 触发条件 | 如"连续 5 次调用失败""响应耗时超过 30 秒""Token 余量低于 10%" |
| 告警级别 | 紧急 / 严重 / 警告 / 提示                          |
| 通知方式 | 站内消息 / 短信 / 邮件 / 企业微信                      |
| 通知对象 | 指定用户或角色                                    |
| 启用状态 | 开关（直接切换，即刻生效）                              |
| 操作   | 「编辑」「删除」按钮                                 |

##### 4.2.3 新建/编辑告警规则（右侧抽屉）

点击「新建规则」或列表中的「编辑」，从右侧滑出抽屉面板（宽约 50%），以单页滚动表单承载四步配置。

**第一步：基本信息**

| 字段   | 类型   | 说明                                            |
| ---- | ---- | --------------------------------------------- |
| 规则名称 | 文本输入 | 必填，最大 50 字符，建议以"对象+场景+告警"命名，如"GPT-4o模型调用失败告警" |
| 规则描述 | 文本域  | 选填，说明该规则的用途和覆盖范围                              |
| 启用状态 | 开关   | 默认开启，关闭后规则不生效但不删除配置                           |

**第二步：监控对象与触发条件**

| 字段     | 类型   | 说明                                                                                                        |
| ------ | ---- | --------------------------------------------------------------------------------------------------------- |
| 监控对象类型 | 下拉单选 | 智能体运行 / 模型调用 / API 响应 / 连接器 / 知识库检索 / 资源配额                                                                |
| 监控范围   | 动态配置 | 根据对象类型动态展开——全部资源 / 指定空间 / 指定智能体 / 指定模型 / 指定连接器，选择"指定XX"后出现搜索多选器勾选具体对象                                     |
| 触发指标   | 下拉单选 | 根据对象类型动态切换可选指标：调用失败次数 / 响应耗时 / 错误率 / Token余量 / 连接状态变更 / 服务离线 / 检索超时 / 配额余量 等                              |
| 触发条件   | 组合配置 | 由三部分组成：聚合方式（连续N次 / 最近N分钟内累计 / 单次）+ 比较运算符（> / < / ≥ / ≤）+ 阈值（数值输入框）。示例："连续 5 次 调用失败"、"最近 30 分钟 内错误率 > 20%" |
| 静默时间   | 数字输入 | 同一告警触发后在静默时间内不再重复产生新告警事件，避免告警风暴，默认 5 分钟                                                                   |

**第三步：告警级别与通知**

| 字段   | 类型   | 说明                                                                          |
| ---- | ---- | --------------------------------------------------------------------------- |
| 告警级别 | 单选卡片 | 紧急（红色）/ 严重（橙色）/ 警告（黄色）/ 提示（蓝色），每种级别展示视觉预览和适用场景说明                            |
| 通知方式 | 多选   | 站内消息（默认必选）/ 短信 / 邮件 / 企业微信，勾选后展开对应配置项（如邮件需填写接收邮箱列表）                         |
| 通知对象 | 多选   | 指定用户（搜索多选）/ 指定角色（下拉多选，如空间管理员、平台运维），支持混合选择                                   |
| 通知模板 | 文本域  | 自定义通知消息模板，支持变量占位符：{{告警名称}} {{告警级别}} {{触发对象}} {{触发时间}} {{当前值}} {{阈值}}，提供预览按钮 |

**第四步：确认与提交**

汇总展示本次配置的所有信息，以分区卡片形式呈现基本信息和完整触发规则摘要，点击「保存」提交。编辑模式下额外展示最后更新人和更新时间。

**抽屉交互**：

- 抽屉从右侧滑出，背景页面半透明遮罩，不影响告警规则列表的浏览
- 点击「保存」后抽屉关闭，规则列表刷新，Toast 提示成功
- 点击抽屉外区域或右上角关闭按钮可关闭抽屉，关闭时若有未保存内容弹出确认提示
- 新建和编辑复用同一抽屉组件，编辑时表单预填已有规则数据

#### 4.3 通用交互行为

- Tab 切换时保留各自页面内的筛选状态
- 新告警到达时浏览器标题栏闪烁或页面顶部出现通知横幅
- 告警记录列表支持**自动刷新**（默认 30 秒，可调整或关闭）
- 批量操作：支持勾选多条告警后一键标记为"已忽略"或"已解决"
