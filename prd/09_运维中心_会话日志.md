### 五、会话日志

会话日志提供平台所有智能体交互记录的集中检索与审计能力，覆盖全空间、全智能体的对话会话，支持按多维度筛选、关键词搜索、对话明细回放和日志导出。

#### 5.1 页面整体布局

- 顶部：筛选条件栏（横排多条件组合）
- 中部：会话列表（表格形式）
- 点击行展开：对话明细内嵌面板（在列表内展开，非弹窗）

#### 5.2 筛选条件栏

| 筛选项   | 类型      | 说明                               |
| ----- | ------- | -------------------------------- |
| 时间范围  | 日期范围选择器 | 默认近七天，支持自定义                      |
| 空间    | 下拉多选    | 可筛选一个或多个空间的日志                    |
| 智能体   | 搜索多选    | 输入智能体名称模糊匹配后勾选，支持跨空间多选           |
| 使用渠道  | 下拉      | 全部 / Web端 / API调用 / 企业微信 / 第三方集成 |
| 状态    | 下拉      | 全部 / 成功 / 报错                     |
| 关键词搜索 | 文本输入    | 在用户提问和智能体回复内容中全文检索               |

筛选条件变更后实时刷新列表。

#### 5.3 会话列表

**列表展示字段**：

| 列名       | 说明                              |
| -------- | ------------------------------- |
| 会话 ID    | 缩略展示，支持复制                       |
| 使用渠道     | 渠道来源标签（Web/API/企微/第三方）          |
| 智能体      | 智能体名称，可点击以右侧抽屉打开该智能体的监控详情（见第六节） |
| 所属空间     | 空间名称                            |
| 使用者      | 用户姓名                            |
| 对话标题     | 会话首条消息摘要                        |
| 消息数      | 该会话包含的对话轮数                      |
| Token 消耗 | 该会话累计 Token 消耗                  |
| 开始时间     | 会话创建时间                          |
| 最后活跃     | 最后一次对话时间                        |
| 状态       | 正常运行 / 部分报错 / 全部报错              |
| 操作       | 「查看明细」「导出」按钮                    |

**列表交互**：

- 默认按最后活跃时间倒序排列
- 支持分页浏览，默认每页 20 条
- 点击行展开内嵌对话明细面板
- 支持按时间、Token 消耗排序

#### 5.4 对话明细面板

点击「查看明细」或行展开后，在列表行下方内嵌展开对话明细面板。

**面板顶部**：

- 会话基本信息摘要：智能体名称、使用者、时间范围、总消息数、总 Token 消耗
- 「导出对话明细」按钮：将完整对话导出为 PDF

**对话时间线**（纵向滚动，每轮对话为一个卡片块）：

每条对话卡片包含：

- 角色标签：「用户」（左侧蓝色标识）/「智能体」（右侧绿色标识）
- 时间戳：精确到秒
- 内容：用户输入原文 / 智能体输出原文（Markdown 渲染展示）
- 元信息行（仅智能体消息展示）：
  - 回复耗时（ms）
  - Token 消耗（输入/输出）
  - 模型名称
  - 是否报错（红色标签标记）

**明细内搜索**：

- 面板内嵌搜索条，输入关键词在对话内容中实时高亮定位
- 支持按角色（全部/用户/智能体）、是否报错快速过滤对话轮次

#### 5.5 通用交互行为

- 会话列表支持**自动刷新**（默认关闭，可开启 30 秒间隔）
- 明细面板支持**独立滚动**，不影响列表浏览
- 列表和明细均提供「导出」功能：
  - 列表导出：将当前筛选条件下的会话列表导出为 Excel
  - 明细导出：将单次会话的完整对话内容导出为 PDF，含排版渲染
