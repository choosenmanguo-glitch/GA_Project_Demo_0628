## 资源广场与我的资源

资源广场子系统作为平台资源汇聚、分发与管控的中枢，面向平台管理员、资源管理者、审批人及普通用户四类角色，提供模型、API、连接器、知识库、提示词、插件工具、数据连接七类资源的标准化接入、集中发布、分级授权、审批流转及安装运维等全生命周期管理能力。

本章聚焦开发中心视角下的**资源广场**和**我的资源**两大页面。资源管理与权限管理归属管理中心。

---

### 一、资源广场

资源广场是全体用户发现与获取平台资源的统一入口。已上架资源按卡片网格展示，支持多维检索、详情预览与使用申请。

#### 1.1 页面整体布局

```
┌─────────────────────────────────────────────────┐
│  统计卡片行                                       │
│  [资源总数] [模型] [API] [MCP] [知识库]             │
├─────────────────────────────────────────────────┤
│  类型Tab:  全部 | 模型 | API | MCP | 知识库         │
│  搜索: [关键词搜索框]                              │
├─────────────────────────────────────────────────┤
│                                                  │
│  资源卡片网格（4列）                               │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌─────┐ │
│  │ 资源卡片   │ │ 资源卡片   │ │ 资源卡片   │ │     │ │
│  └──────────┘ └──────────┘ └──────────┘ └─────┘ │
│                                                  │
│  分页器                                          │
└─────────────────────────────────────────────────┘
```

#### 1.2 统计卡片

| 指标     | 说明                      |
| ------ | ----------------------- |
| 资源总数   | 平台已上架的资源总数              |
| 模型数量   | 类型为「模型」的资源数             |
| API数量  | 类型为「API」的资源数            |
| 连接器数量  | 类型为「连接器」的资源数            |
| 知识库数量  | 类型为「知识库」的资源数            |
| 提示词数量  | 类型为「提示词」的资源数            |
| 插件工具数量 | 类型为「插件工具」的资源数           |
| 数据连接数量 | 类型为「数据连接」的资源数           |

每个统计卡片可点击，点击后联动切换到对应类型的 Tab 筛选。

#### 1.3 筛选与检索

| 筛选项     | 类型     | 说明                                |
| ------- | ------ | --------------------------------- |
| 资源类型    | Tab 页签 | 全部 / 模型 / API / 连接器 / 知识库 / 提示词 / 插件工具 / 数据连接 |
| 关键词搜索   | 文本输入   | 按资源名称、描述、所有权人模糊搜索，实时过滤刷新列表       |

#### 1.4 资源卡片

每张卡片展示：

- 资源类型图标（按模型/API/MCP/知识库着色）
- 置顶标识（金色角标）
- 资源名称
- 资源类型 + 子类别标签
- 部署方式标签（内网/公网）
- 资源描述摘要（两行截断）
- 所有权人
- 发布日期
- 安装次数
- 「查看详情」按钮

默认排序：置顶资源优先，其余按发布日期倒序。

#### 1.5 资源详情抽屉

点击「查看详情」从右侧弹出抽屉（宽度 560px），展示：

- **基本信息区**：资源名称、类型、子类别、描述
- **统计信息区**：累计安装次数
- **归属信息区**：所有权人、发布日期、当前公开策略
- **授权状态区**：
  - 已获授权：绿色标识，可查看技术对接信息
  - 未授权：橙色提示 + 「申请使用」按钮
  - 审核中：按钮置灰显示「审核中」
- **详情内容区**：Markdown 渲染展示资源介绍与对接文档

#### 1.6 申请使用

未授权用户点击「申请使用」后弹出申请表单：

| 字段     | 说明                                       |
| ------ | ---------------------------------------- |
| 资源名称   | 自动填充，不可编辑                                |
| 所有权人   | 自动填充，不可编辑                                |
| 授权时效   | 单选：长期有效 / 指定日期（选择后展开日期选择器）               |
| 申请理由   | 选填文本域，最多 100 字                           |

提交后校验是否已有待审批记录，通过后写入审批表并通知审批人。

### 二、我的资源

我的资源是面向资源使用者的个人授权资源管理中心，展示当前用户已获得使用权限的全部资源，支持安装与凭证管理。

#### 2.1 页面整体布局

```
┌─────────────────────────────────────────────────┐
│  统计卡片行                                       │
│  [已获授权] [已安装] [未安装] [即将到期]              │
├─────────────────────────────────────────────────┤
│  Tab:  全部 | 模型 | API | MCP | 知识库             │
│  搜索: [关键词搜索框]   [安装状态筛选]   [来源筛选]     │
│  操作: [一键安装]  [个人API Key]                    │
├─────────────────────────────────────────────────┤
│                                                  │
│  资源卡片网格（4列）                               │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌─────┐ │
│  │ 资源卡片   │ │ 资源卡片   │ │ 资源卡片   │ │     │ │
│  └──────────┘ └──────────┘ └──────────┘ └─────┘ │
│                                                  │
│  分页器                                          │
└─────────────────────────────────────────────────┘
```

#### 2.2 统计卡片

| 指标     | 说明                   |
| ------ | -------------------- |
| 已获授权   | 当前用户已获得使用权限的资源总数     |
| 已安装    | 安装状态为「已安装」的资源数       |
| 未安装    | 安装状态为「未安装」的资源数       |
| 即将到期   | 授权距离到期不足 7 天的资源数     |

#### 2.3 筛选与检索

| 筛选项    | 类型     | 说明                              |
| ------ | ------ | ------------------------------- |
| 资源类型   | Tab    | 全部 / 模型 / API / 连接器 / 知识库 / 提示词 / 插件工具 / 数据连接 |
| 关键词搜索  | 文本输入   | 按资源名称、描述模糊搜索                   |
| 安装状态   | 下拉     | 全部 / 已安装 / 未安装 / 安装失败           |
| 来源     | 下拉     | 全部 / 我申请的 / 共享给我的 / 管理员授权的       |

#### 2.4 资源卡片

在广场卡片基础上扩展：

- 安装状态标签（已安装绿色 / 未安装灰色 / 安装失败红色 / 安装中加载动画）
- 来源标签（我申请的 / 共享给我的 / 管理员授权）
- 操作按钮根据安装状态动态切换：
  - 未安装 → 「安装资源」
  - 已安装 → 「重新安装」
  - 安装失败 → 「重新安装」
  - 安装中 → 按钮置灰加载

#### 2.5 批量安装

点击「一键安装」进入多选模式：
- 每张卡片出现复选框
- 顶部按钮切换为「全选」「取消多选」「执行安装(N)」
- 安装数量上限 10 个
- 确认后逐个安装，完成后刷新状态

#### 2.6 个人 API Key

页面顶部提供 API Key 管理入口：
- 默认脱敏展示（首尾若干字符 + 中间星号）
- 支持切换明文预览
- 一键复制到剪贴板
- 无 Key 时自动创建

### 三、数据结构

#### 3.1 资源广场记录

| 字段       | 说明                                       |
| -------- | ---------------------------------------- |
| 记录唯一标识   | 主键                                       |
| 资源名称     | 显示名称                                     |
| 唯一标识Key  | 系统内唯一标识                                  |
| 资源类型     | 模型 / API / 连接器 / 知识库 / 提示词 / 插件工具 / 数据连接  |
| 子分类      | 如大模型/向量化模型/Rerank模型等                      |
| 部署方式     | 内网 / 公网                                  |
| 描述文本     | 简短描述                                     |
| 资源介绍     | Markdown 格式详细介绍                           |
| 公开策略     | 完全公开 / 公开可见授权可用 / 授权可见                    |
| 所有权人     | 用户标识                                     |
| 上架状态     | 待上架 / 已上架 / 已下架                          |
| 置顶标识     | 布尔值                                      |
| 安装次数     | 累计安装数                                    |
| 发布日期     | 上架时间                                     |
| 技术配置     | JSON，按类型存储不同配置（Base URL、API Key、Endpoint等） |

#### 3.2 用户授权资源记录

| 字段       | 说明                                       |
| -------- | ---------------------------------------- |
| 记录唯一标识   | 主键                                       |
| 用户标识     | 关联用户                                     |
| 资源标识     | 关联资源                                     |
| 授权来源     | 申请获取 / 公开共享 / 管理员授权                      |
| 授权到期日期   | 可选，空值表示长期有效                              |
| 安装状态     | 未安装 / 已安装 / 安装失败                         |
| 调用凭证标识   | 关联 API Key                                |

#### 3.3 使用申请记录

| 字段     | 说明                |
| ------ | ----------------- |
| 记录唯一标识 | 主键                |
| 资源标识   | 关联资源              |
| 申请人标识  | 关联用户              |
| 所有权人标识 | 关联用户              |
| 授权时效   | 长期有效/指定日期         |
| 授权到期日期 | 可选                |
| 申请理由   | 文本                |
| 审批状态   | 待审批/通过/驳回         |
| 审批人标识  | 关联用户              |
| 审批意见   | 文本                |
| 申请时间   | 时间戳               |
| 审批时间   | 时间戳               |
