### 二、资源监控

资源监控提供平台核心资源的运营数据监控能力，覆盖智能体、模型、知识库、工具和连接器五类资源。左侧导航中每个资源类型对应一个独立页面视图，点击菜单项直接进入对应的分析页面。各页面共享统一的布局结构。

#### 2.0 各页面通用布局

每个资源分析页面采用相同的布局模式：

- 顶部：时间范围选择器（近一天 / 近七天 / 近三十天 / 自定义日期范围）+ 空间范围选择器（全部空间/指定空间）
- 指标概览卡片行（4-5 张核心指标卡）
- 图表区：趋势图 + 分布/排行图（左右或上下排列）
- 明细列表区：可展开的数据明细表格

***

#### 2.1 智能体分析（菜单项：智能体分析）

**指标概览卡片组**：

- 累计智能体数：创建总数及环比变化
- 本月新增智能体数
- 累计使用次数：全平台智能体被调用总次数
- 活跃智能体数：近三十天有调用记录的智能体数量
- 平均运行成功率：成功完成次数占总调用次数的比例

**图表区**：

| 图表          | 类型        | 说明                      |
| ----------- | --------- | ----------------------- |
| 使用次数趋势      | 折线图       | 按日/周展示智能体总调用次数变化        |
| 智能体类型分布     | 饼图/环形图    | 标准智能体 / 流程智能体 / 自主智能体占比 |
| 活跃智能体 TOP10 | 横向条形图     | 按调用次数降序排行               |
| 新增智能体趋势     | 折线图 + 柱状图 | 按日/周展示新增智能体数量           |

**明细列表**：

- 表格列：智能体名称、所属空间、类型、创建时间、累计调用次数、近三十天调用次数、运行成功率、状态
- 支持按智能体名称搜索、按空间/类型/状态筛选
- 支持按调用次数、成功率排序
- 点击智能体名称以右侧抽屉打开该智能体的监控详情页（见第六节）

#### 2.2 模型分析（菜单项：模型分析）

**指标概览卡片组**：

- 接入模型总数：平台已接入模型数量
- 累计 Token 消耗量：全平台模型调用 Token 总消耗
- 本月 Token 消耗量
- 累计调用费用估算
- 活跃模型数：近三十天有调用记录的模型数量

**图表区**：

| 图表             | 类型     | 说明                   |
| -------------- | ------ | -------------------- |
| Token 消耗趋势     | 面积图    | 按日/周展示全平台 Token 消耗变化 |
| 各模型消耗占比        | 饼图/环形图 | 按模型维度展示 Token 消耗占比   |
| 模型调用次数排行       | 横向条形图  | 按调用次数降序展示各模型排行       |
| 按空间 Token 消耗排行 | 横向条形图  | 按空间维度展示 Token 消耗排行   |

**明细列表**：

- 表格列：模型名称、模型类型（大模型/向量模型/重排序/语音识别/语音合成）、所属供应商、调用次数、Token 消耗量、费用估算、平均响应耗时
- 支持按模型名称搜索、按类型/供应商筛选
- 支持按 Token 消耗量、调用次数排序

#### 2.3 知识库分析（菜单项：知识库分析）

**指标概览卡片组**：

- 知识库总数
- 累计文档总量
- 累计检索调用次数
- 平均检索命中率

**图表区**：

| 图表       | 类型    | 说明                |
| -------- | ----- | ----------------- |
| 检索调用趋势   | 折线图   | 按日/周展示知识库检索调用次数变化 |
| 知识库检索量排行 | 横向条形图 | 按检索次数降序展示各知识库     |
| 知识库文档量分布 | 柱状图   | 各知识库文档数量对比        |
| 检索命中率趋势  | 折线图   | 平均相似度得分变化趋势       |

**明细列表**：

- 表格列：知识库名称、所属空间、文档数量、向量化状态、累计检索次数、近三十天检索次数、平均相似度得分
- 支持按知识库名称搜索、按空间筛选

#### 2.4 工具分析（菜单项：工具分析）

**指标概览卡片组**：

- 工具总数（内置 + 自定义 + 工作流 + 扩展）
- 累计工具调用次数
- 活跃工具数：近三十天有调用记录的工具数量
- 工具调用成功率

**图表区**：

| 图表          | 类型     | 说明                              |
| ----------- | ------ | ------------------------------- |
| 工具调用趋势      | 折线图    | 按日/周展示工具总调用次数变化                 |
| 工具类型分布      | 饼图/环形图 | 内置工具 / 自定义接口 / 工作流工具 / 连接器 调用占比 |
| 工具调用量 TOP10 | 横向条形图  | 按调用次数降序展示热门工具                   |

**明细列表**：

- 表格列：工具名称、工具类型、所属空间/全局、累计调用次数、近三十天调用次数、调用成功率、状态
- 支持按工具名称搜索、按类型/空间筛选

#### 2.5 连接器分析（菜单项：连接器分析）

**指标概览卡片组**：

- 连接器总数
- 活跃连接数：当前握手状态为"已连接"的服务数
- 累计调用次数
- 连接异常数：当前握手状态为"连接异常/离线"的服务数

**图表区**：

| 图表        | 类型     | 说明                 |
| --------- | ------ | ------------------ |
| 连接器调用趋势   | 折线图    | 按日/周展示连接器工具调用次数变化  |
| 连接器调用排行   | 横向条形图  | 按调用次数降序展示各连接器      |
| 连接状态分布    | 饼图/环形图 | 已连接 / 连接异常 / 离线 占比 |
| 连接器响应耗时趋势 | 折线图    | 连接器调用平均响应耗时变化      |

**明细列表**：

- 表格列：连接器名称、连接模式（SSE/stdio）、连接状态（彩色标签）、暴露工具数、累计调用次数、近三十天调用次数、平均响应耗时
- 支持按名称搜索、按连接状态/连接模式筛选
- 点击连接器名称进入连接器详情页

#### 2.6 通用交互行为

- 所有图表支持**鼠标悬停数据提示**（tooltip）
- 折线图/面积图支持**数据点下钻**到当日的明细记录
- 时间范围切换时，所有图表和卡片数据**联动脉冲刷新**
- 明细列表支持**导出为 Excel** 功能
- 图表区提供**全屏查看**按钮
