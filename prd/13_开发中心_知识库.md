## 开发中心\_知识库

知识库模块是开发中心"组件管理"下的核心功能，为智能体提供可检索的高质量上下文数据支撑。支持三类知识库的创建与管理：简易知识库（面向普通用户，上传即用）、专业知识库（面向知识库专家，提供自定义切分策略与数据清洗能力）和外部知识库（通过 API 接入外部已有知识库服务）。

***

#### 1.2 数据指标卡片区

页面顶部横排展示 4 张统计卡片，快速呈现当前空间知识库核心指标。与 [04\_开发中心\_空间运营.md](./04_开发中心_空间运营.md) 中知识库数统计共享数据源，此处侧重按类型分组展示。

| 卡片    | 说明                            | 点击行为                         |
| ----- | ----------------------------- | ---------------------------- |
| 知识库总数 | 当前空间内知识库总数（可用 / 向量化中 / 异常分项数） | 点击联动切换至「全部」Tab               |
| 简易知识库 | 简易知识库数量 + 累计文件数               | 点击联动切换至「简易知识库」Tab + 过滤对应类型数据 |
| 专业知识库 | 专业知识库数量 + 累计文件数               | 点击联动切换至「专业知识库」Tab + 过滤对应类型数据 |
| 外部知识库 | 外部知识库数量（已连接 / 异常分项数）          | 点击联动切换至「外部知识库」Tab + 过滤对应类型数据 |

每张卡片为独立卡片样式，包含数值（大字号加粗）和次级说明文字（小字灰色），点击卡片的交互行为为联动切换下方 Tab 并刷新卡片列表。

#### 1.3 筛选区与页面级操作区

遵循平台通用管理页布局（[00\_整体布局框架.md](./00_整体布局框架.md) 3.5 节），筛选区与页面级操作区同处一行、左右分区。

**左侧筛选区**：

| 元素        | 类型       | 说明                                         |
| --------- | -------- | ------------------------------------------ |
| 类型 Tab 页签 | Tab/胶囊按钮 | 全部 / 简易知识库 / 专业知识库 / 外部知识库，带各类型数量角标，点击切换筛选 |
| 状态筛选      | 下拉多选     | 可用 / 向量化中 / 异常，默认全部                        |
| 搜索框       | Input    | 按知识库名称模糊搜索，圆角输入框，带搜索图标；支持实时过滤或回车触发         |
| 「重置」按钮    | Button   | 清空所有筛选条件，恢复默认视图                            |

**右侧页面级操作区**：

| 元素       | 类型     | 说明                  |
| -------- | ------ | ------------------- |
| 创建知识库 按钮 | Button | 主色按钮（蓝色），点击弹出类型选择弹窗 |

> **说明**：类型 Tab 采用与 [12\_开发中心\_资源广场.md](./12_开发中心_资源广场.md) 一致的胶囊按钮样式，每个 Tab 附带数量徽标，选中态高亮为对应类型主题色。

#### 1.4 知识库卡片

卡片网格以 4 列自适应排列（窗口缩窄时自适应为 3 列或 2 列，参见 [00\_整体布局框架.md](./00_整体布局框架.md) 6 节）。每张卡片采用与 [12\_开发中心\_资源广场.md](./12_开发中心_资源广场.md) 中资源卡片一致的视觉规范。

**卡片视觉效果**：白色背景 + 灰色边框 + 圆角。悬停时边框高亮并辅以浅层阴影，卡片整体微上移。

卡片内部内容结构（自上而下）：

| 区域            | 说明                                                                                                    |
| ------------- | ----------------------------------------------------------------------------------------------------- |
| **顶部：图标区**    | 左侧：知识库类型图标置于圆角方形容器内（简易知识库=蓝色底文件图标，专业知识库=紫色底结构图标，外部知识库=橙色底 API 图标）。右侧：类型小标签（简易/专业/外部，灰色背景）+「...」更多菜单按钮 |
| **名称 + 类型说明** | 知识库名称（加粗，超长截断 + hover 展示完整名称）；下方一行小字类型说明（如"文档知识库"、"结构化知识库"、"外部接入"）                                    |
| **描述文本**      | 知识库描述文本，小字灰色，最多显示 2 行                                                                                 |
| **指标与状态**     | 文件数统计（仅简易和专业知识库，格式："N 个文件"，带文件图标）；                                                                    |
| **底部信息栏**     | 左侧：创建日期（`YYYY-MM-DD` 格式）+ 创建人（分隔符「\|」）。右侧：启用/停用 Switch 开关                                             |

**整体交互**：整张卡片可点击，点击后进入对应知识库的详情视图。更多菜单区域和 Switch 开关区域拦截点击冒泡，各自独立响应。

#### 1.5 更多菜单

点击卡片右上角「...」按钮弹出下拉菜单（Dropdown）：

| 菜单项     | 说明                                    |
| ------- | ------------------------------------- |
| 重命名     | 弹出重命名模态弹窗（宽度约 420px）                  |
| 编辑配置    | 外部知识库打开编辑配置抽屉（同创建流程 2.4）；其他类型暂以占位方式展示 |
| ——————— | 分割线                                   |
| 删除知识库   | 红色文字，弹出删除确认模态弹窗，二次确认后执行软删除            |

#### 1.6 分页器

采用全局统一分页器组件

#### 1.7 交互行为

- 数据指标卡片点击后联动切换下方类型 Tab 并刷新数据
- 类型 Tab 切换时搜索关键词保留，分页重置至第 1 页
- 知识库卡片整张可点击，点击后进入对应类型的详情视图
- 创建知识库成功后自动添加到列表顶部，关闭抽屉/弹窗
- 删除操作二次确认后执行，从列表中移除对应卡片
- 外部知识库编辑模式下，配置数据预填充到表单中

### 二、创建知识库流程

根据平台交互容器分级（参见 [00\_整体布局框架.md](./00_整体布局框架.md) 第四章），创建流程使用**模态弹窗**承载类型选择 + **右侧 Drawer 抽屉**承载具体创建表单。

点击列表页「创建知识库」按钮后，弹出**类型选择模态弹窗**，用户选择知识库类型后进入对应的创建流程。

#### 2.1 类型选择弹窗（模态弹窗）

居中固定宽度约 620px，以三列网格展示三种知识库类型卡片：

| 类型    | 图标           | 说明                                             |
| ----- | ------------ | ---------------------------------------------- |
| 简易知识库 | 文件夹图标（蓝色底色）  | 只需上传文件即可自动切块并形成向量表示，适合不懂知识库构建的人群快速上手使用         |
| 专业知识库 | 方块图标（灰色底色）   | 提供自定义切分策略和数据清洗能力，适合知识库专家针对特定业务进行个性化整理和干预       |
| 外部知识库 | API 图标（灰色底色） | 无缝接入外部已有的知识库服务或 API，用于为当前系统和智能体构建提供更丰富的上下文数据支持 |

每张卡片悬停时边框高亮并放大图标。点击任意卡片进入对应创建流程。

#### 2.2 创建简易知识库

以**右侧 Drawer 抽屉**承载，包含以下字段：

| 字段    | 类型       | 说明                                   |
| ----- | -------- | ------------------------------------ |
| 知识库名称 | Input    | 必填                                   |
| 知识库类型 | Select   | 必填，下拉选项：文档知识库 / 结构化数据知识库；默认文档知识库     |
| 知识库头像 | 图标选择器    | 单选：选择头像 / 上传头像；显示虚线方框上传区域            |
| 知识库介绍 | TextArea | 选填，多行文本输入                            |
| 向量化模型 | Select   | 下拉选择，选项：bge-m3 / text-embedding-v2 等 |

底部操作按钮：取消 / 提交。

#### 2.3 创建专业知识库

以**右侧 Drawer 抽屉**承载，包含以下字段和区域：

| 区域/字段                  | 类型       | 说明                                     |
| ---------------------- | -------- | -------------------------------------- |
| 名称                     | Input    | 必填                                     |
| 嵌入模型                   | Select   | 必填，默认 bge-m3，选项以 AI 标签图标 + 模型名展示       |
| 解析方法                   | Radio    | 单选：内置 / 选择 pipeline；默认内置               |
| 内置（parse方法）            | Select   | 必填，选项：General / Q\&A / Resume / Manual |
| 描述                     | TextArea | 选填                                     |
| 头像                     | 上传区域     | 虚线方框 + 上传提示，支持最大 4MB 文件                |
| Ingestion Pipeline 配置区 | —        | 以下为文档摄入管线的细分参数                         |
| PDF解析器                 | Select   | 默认 DeepDOC                             |
| 建议文本块大小                | Slider   | 滑块 + 数值，范围 0-2048，默认 512               |
| 文本分段标识符                | Input    | 默认 "\n"                                |
| Child Chunk Retrieval  | Switch   | 开关，默认关闭                                |
| PageIndex              | Switch   | 开关，默认关闭                                |
| 图像与表格上下文窗口             | Slider   | 滑块 + 数值，范围 0-10，默认 2                   |
| 自动元数据                  | Switch   | 开关 + 设置按钮                              |
| Overlapped %           | Slider   | 滑块 + 数值，范围 0-100，默认 0                  |

底部操作按钮：取消 / 保存。

#### 2.4 创建外部知识库

以**右侧 Drawer 抽屉**承载，包含以下字段：

| 字段           | 类型                            | 说明                                    |
| ------------ | ----------------------------- | ------------------------------------- |
| 顶部提示         | 说明文本                          | "通过 API 和知识库 ID 连接到外部知识库。目前仅支持检索功能……" |
| 外部知识库名称      | Input                         | 必填                                    |
| 知识库描述        | TextArea                      | 选填                                    |
| API Endpoint | Input                         | 必填，带"了解如何创建外部知识库 API"帮助链接             |
| API Key      | Input.Password                | 必填，加密存储；底部提示"您的 API Token 将进行加密存储"    |
| 外部知识库 ID     | Input                         | 必填                                    |
| 召回设置         | —                             | <br />                                |
| Top K        | InputNumber + Slider          | 范围 1-10，默认 4                          |
| Score 阈值     | Switch + InputNumber + Slider | 可开启/关闭，开启后支持设定 0-1 阈值，默认 0.5          |

底部操作按钮：取消 / 连接（提交时显示 loading 状态，模拟 API 连通性校验，失败时提示"连接外部知识库失败，请检查 API Endpoint 或 Key 是否正确"）。

外部知识库编辑模式：复用同一抽屉，填充已有配置数据，底部按钮文字改为"保存"。

### 三、详情视图

点击知识库卡片进入详情视图，简易知识库和专业知识库共用统一的 **Tab 页签**布局（页面内三级 Tab 导航，参见 [00_整体布局框架.md](./00_整体布局框架.md) 3.4 节），外部知识库采用独立的单列信息卡片布局。所有详情视图顶部统一展示返回箭头 + 知识库名称。

#### 3.1 简易知识库 & 专业知识库通用布局

两类知识库共享以下 Tab 结构：

| Tab  | 内容                              | 简易知识库 | 专业知识库 |
| ---- | ------------------------------- | :---: | :---: |
| 文件   | 文件管理（上传、搜索、状态筛选、文件列表）+ 分页器    | ✓    | ✓    |
| 检索测试 | 知识库检索测试区域                       | ✓    | ✓    |
| 操作记录 | 知识库相关操作日志列表                     | ✓    | ✓    |
| 基础设置 | 知识库基本配置信息（类型、模型、权限等，只读或可编辑）    | ✓    | ✓    |

各 Tab 内容在不同知识库类型下的差异如下：

**（1）「文件」Tab**

| 对比项     | 简易知识库                                           | 专业知识库                    |
| -------- | ----------------------------------------------- | ----------------------- |
| 左侧目录面板   | 有。目录搜索 + 新建目录 + 目录树（Tree，全部展开）                     | 无                       |
| 提示条      | 无                                               | 顶部蓝色背景提示条："知识库文档在修改或上传后需要一定的时间进行向量化加载……" |
| 文件表格列    | 序号 / 文件名称 / 格式 / 文件体积 / 文件状态 / 所在目录 / 操作（删除） + 行选择 | 名称 / 上传日期 / 文件体积 / 文件状态 / 操作（启用/停用 Switch + 删除按钮） + 行选择 |
| 文件状态展示   | 绿色文本 + 绿点："已向量化"                                    | 彩色状态标签                   |
| 操作按钮     | 上传文件 / 导入文件 + 批量操作                                  | 批量导入                     |
| 文件上传弹窗   | 有（创建时解析开关 + 拖拽上传区域）                                 | 无独立弹窗，直接上传               |

**简易知识库「文件」Tab 内布局**：左侧面板（约 256px 宽）展示目录树，右侧主内容区展示筛选栏 + 文件表格。筛选栏包含：查看本级及下级文件（Radio）、文件名称搜索、文件状态下拉、使用状态下拉、「搜索」「重置」「设置」按钮。

**简易知识库文件上传弹窗**：标题"上传文件"，创建时解析开关（默认关闭），虚线拖拽上传区域（中心上传图标 + 提示文字 + 文件大小/数量限制说明），底部「保存」按钮。

**（2）「检索测试」Tab**：提供检索输入框与检索结果列表，用于测试知识库的语义检索效果。简易知识库与专业知识库共用此 Tab。

**（3）「操作记录」Tab**：展示知识库相关操作日志列表（文件上传、配置修改、状态变更等）。两种知识库共用。

**（4）「基础设置」Tab**：展示当前知识库的基础配置信息（如知识库类型、嵌入模型、权限设置等）。简易知识库以只读展示为主，专业知识库支持部分可编辑项。

#### 3.2 外部知识库详情

详情页为居中展示的单列信息卡片（最大宽度约 4xl），分区展示：

**基本信息区域**：

- 知识库名称、状态（绿色圆点 + "可用"）、描述

**API 配置区域**（灰底标题行）：

- API Endpoint（灰色底色只读文本框）
- API Key（脱敏显式，仅显示末尾几位）
- 外部知识库 ID（灰色底色只读文本框）

**召回设置区域**（灰底标题行）：

- Top K：InputNumber（禁用态）+ Slider（禁用态，灰色不可拖拽）
- Score 阈值：InputNumber（禁用态）+ Slider（禁用态）

**顶部操作按钮**：编辑配置（点击进入编辑模式抽屉，同 2.4 创建流程）

### 五、交互行为（补充）

以下为列表视图之外（详情视图、跨视图）的通用交互约定（列表视图自身交互行为见 1.7 节）：

- 详情视图顶部返回箭头回到列表视图，保持返回前的筛选条件和分页位置
- 提交外部知识库时模拟连通性校验（1.5 秒延迟），失败时展示错误提示："连接外部知识库失败，请检查 API Endpoint 或 Key 是否正确"
- 简易知识库详情页中，文件表格支持 checkbox 多选，选中后可进行批量操作（批量删除）
- 专业知识库详情页中，Tab 切换时各 Tab 保持独立的筛选与分页状态

### 六、交互容器总结
