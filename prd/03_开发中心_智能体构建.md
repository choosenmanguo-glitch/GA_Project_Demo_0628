## 智能体构建需求设计

智能体构建是开发中心的核心能力模块，面向空间内开发者提供多种智能体创建与配置方式。平台支持三种智能体类型（标准智能体、流程智能体、自主智能体）和三种创建方式（表单构建、智能构建、模板构建），覆盖从零搭建到快速复用的不同场景需求。

***

### 一、创建方式选择页

点击左侧「智能体构建」菜单后，进入创建方式选择页。该页面不展示列表，而是以选择面板引导用户选择创建路径。

#### 1.1 页面布局

- 顶部标题：「创建智能体」
- 居中三栏横向排列的三张大型选择卡片，对应三种创建方式

#### 1.2 选择卡片

| 卡片   | 标题    | 描述                                          | 适用场景                              |
| ---- | ----- | ------------------------------------------- | --------------------------------- |
| 表单构建 | 从零搭建  | 选择智能体类型后，进入结构化配置页面，按步骤完成模型、提示词、知识库、工具等组件的装配 | 熟悉平台、需要精细化控制的开发者                  |
| 智能构建 | 对话式创建 | 以自然语言描述需求，AI 助手通过多轮对话逐步明确要求，自动生成完整的智能体配置方案  | 新手用户或希望快速验证想法的场景。对话式创建仅支持自主智能体类型。 |
| 模板构建 | 从模板创建 | 浏览智能体模板市场，选择警务场景预置模板一键复制创建，在模板基础上微调配置       | 快速搭建常见警务业务场景的智能体                  |

每张卡片底部有「开始创建」按钮，点击进入对应的创建流程。

底部提供一行提示文字："不确定从哪里开始？试试智能构建，告诉我你想做什么。"

***

### 二、表单构建

表单构建是精细化的智能体创建方式。用户填写基本信息完成创建后，进入统一的配置页面进行后续设置。

#### 2.1 创建页面

点击「表单构建」后进入创建页，填写智能体基本信息后提交即完成创建。

| 字段 | 类型 | 说明 |
|------|------|------|
| 智能体类型 | 单选卡片 | 标准智能体 / 流程智能体 / 自主智能体，三选一。每张卡片附带类型简介和典型场景举例，点击选中高亮 |
| 子类型 | 单选卡片 | 根据所选智能体类型动态切换：**标准智能体**时从以下 9 种业务子类型中单选（普通助手 / 知识库问答 / 智能分析问数 / 文档编写 / 数据分析报告 / 文件审核 / 智能检索 / 智能抽取 / 智能分类）；**流程智能体**时二选一（工作流 / 对话流）。每张卡片附带简介，选中高亮 |
| 智能体名称 | 文本输入 | 必填，最大 50 字符，校验全局唯一性 |
| 智能体描述 | 文本域 | 选填，描述智能体的用途和适用范围 |
| 头像 | 头像选择器 | 从预设图标库中选择或上传自定义图片，提供默认头像 |

> **标准智能体子类型说明**：
>
> - **普通助手**：基于大语言模型的对话式智能助手，支持模型选型、提示词编排、开场白定义与文件上传策略配置。
> - **知识库问答**：基于知识库的智能问答，支持关联多知识库并配置向量检索参数与重排序模型。
> - **智能分析问数**：基于结构化数据源的智能分析，支持关联数据表与视图，实现自然语言驱动的数据查询与分析。
> - **文档编写**：结合知识库的文档智能生成，支持素材检索、引用溯源与文件上传。
> - **数据分析报告**：基于上传数据文件（CSV/XLSX 等）自动生成包含图表和分析结论的数据分析报告。
> - **文件审核**：对上传文件进行合规性审核与内容质量审查。
> - **智能检索**：基于知识库的精准信息检索，支持检索字段与回复字段配置。
> - **智能抽取**：从非结构化文本中按预设规则提取结构化实体信息。
> - **智能分类**：对输入文本按预设分类规则进行自动归类（支持单标签/多标签分类）。

> **流程智能体子类型说明**：
>
> - **工作流**：设计者将 AI 模型调用、知识检索、条件分支、代码执行等组件抽象为标准节点，通过拖拽、连线、配置的方式组装为可重复执行的自动化流程。适合多步骤分支、条件流转、多部门协查等复杂审批与研判流程。
> - **对话流**：以对话交互为主线的工作流模式，会话变量在整个聊天会话期间持续存在可跨轮次共享。提供答案节点（多模态复合回复）、变量赋值器节点（会话变量覆写/清除/运算）、参数提取器节点等专用组件。适合需要多轮上下文记忆的对话式业务流程。

> **注**：自主智能体无需额外选择子类型——通过 Agent 策略自主规划任务并调用工具完成复杂目标。

点击「创建」按钮提交，系统校验字段合法性后保存并分配全局唯一智能体 ID，自动跳转至该智能体的配置页面。

### 六、智能构建（对话式创建）

智能构建为不熟悉平台配置细节的用户提供 AI 辅助的对话式创建体验。用户以自然语言描述需求，系统通过多轮对话逐步明确意图，自动生成完整的智能体配置方案。

#### 6.1 交互方式

进入智能构建后，页面呈现为对话聊天界面：左侧为对话区，显示 AI 引导提问和用户回复的消息流，底部输入框供用户输入；右侧为实时预览区，根据对话进度动态刷新已生成的配置摘要。

#### 6.2 对话流程

| 阶段    | AI 引导内容                                             | 用户输入                           |
| ----- | --------------------------------------------------- | ------------------------------ |
| 需求收集  | "请描述你想创建的智能体——包括它的用途、适用场景和期望具备的能力。"                 | 自由文本描述，如"我想做一个交通事故现场处理指南的问答助手" |
| 类型确认  | 系统分析语义后推选智能体类型并展示理由："根据你的描述，我建议创建标准智能体，因为…" 用户确认或修改 | 确认或切换类型                        |
| 名称建议  | "我建议命名为'交通事故处理指南问答助手'，你觉得如何？"                       | 确认或自定义                         |
| 能力细化  | 追问："你希望它具备哪些额外能力？比如文件上传、数据分析、多轮对话等。"                | 确认或补充需求                        |
| 生成配置  | 系统生成完整配置方案，右侧预览区实时刷新                                | —                              |
| 审阅与微调 | "以下是生成的完整配置，你可以逐项查看和修改。"                            | 逐项确认或手动调整                      |

#### 6.3 自动生成能力

| 能力        | 说明                                                 |
| --------- | -------------------------------------------------- |
| 智能体类型推断   | 分析描述语义特征——问答/审批类→标准智能体，多步骤分支→流程智能体，多轮推理/自主决策→自主智能体 |
| 自动生成系统提示词 | 生成结构化提示词（角色设定 + 任务边界 + 工作流程 + 输出格式），展示在预览区         |
| 自动匹配知识库   | 根据业务领域语义检索当前空间知识库，按匹配度排序推荐关联                       |
| 自动匹配工具集   | 根据任务类型（文档解析/数据查询/图像识别等）匹配已安装工具，推荐挂载                |
| 自动推荐模型与参数 | 根据任务复杂度、实时性要求推荐合适模型及参数，展示推荐理由                      |

#### 6.4 修正与重建

| 功能      | 说明                                                                  |
| ------- | ------------------------------------------------------------------- |
| 不满意重新生成 | 用户可修改或重写需求描述，再次触发生成新方案                                              |
| 追加修正指令  | 创建完成后进入测试，若效果不达预期可追加修正指令（如"回答太简短""不要引用法规外的内容"），系统结合原始描述和修正指令自适应调整配置 |
| 查看推理过程  | 展示系统分析需求时的关键语义提取、配置决策依据和备选方案，帮助用户理解生成逻辑                             |
| 一键进入调试  | 创建完成后一键跳转至调试面板，形成"创建-测试-修正"闭环                                       |

### 七、从模板创建

从模板创建为用户提供基于预置模板快速构建智能体的路径，降低重复配置成本。

#### 7.1 模板市场

点击「从模板创建」进入模板市场页，顶部为分类筛选栏 + 搜索框，下方为模板卡片网格。

**分类筛选**：客服应答 / 知识问答 / 数据分析 / 文档编写 / 文件审核 / 信息抽取 / 智能分类 / 自定义

**模板卡片**展示元素：模板名称、适用场景标签、包含的组件清单摘要（如"默认模型: GPT-4o · 关联知识库: xx · 挂载工具: 1个"）、累计使用次数、「查看详情」按钮。

**搜索**：按模板名称或场景关键词模糊匹配。

#### 7.2 模板详情

点击模板卡片进入详情预览页，以分区卡片展示模板的全部预置配置：

| 分区      | 内容                   |
| ------- | -------------------- |
| 基本信息    | 名称、描述、适用场景、创建时间、使用次数 |
| 提示词     | 完整系统提示词全文（只读预览）      |
| 模型配置    | 模型名称、参数预设、连续对话等配置    |
| 知识库关联   | 关联的知识库列表及检索参数        |
| 工具集（如有） | 已挂载的工具列表             |
| 对话交互设置  | 开场白、内容审查等预设          |

#### 7.3 一键复制创建

点击「使用此模板」按钮，系统基于模板配置自动创建新的智能体草稿——复制提示词、知识库关联、工具集挂载和模型配置。新智能体出现在智能体管理列表中，与原模板相互独立。用户可在草稿基础上自定义修改名称、描述后保存。

#### 7.4 保存当前为模板

在任意智能体的配置页面中，提供「保存为模板」操作：

| 字段     | 说明                                         |
| ------ | ------------------------------------------ |
| 模板名称   | 必填                                         |
| 适用场景描述 | 选填                                         |
| 分类标签   | 单选（客服应答/知识问答/数据分析/文档编写/文件审核/信息抽取/智能分类/自定义） |

提交后该模板出现在当前空间的自定义模板列表中，空间内其他成员可选用。系统预置模板不可删除。

#### 7.5 模板使用统计

系统展示每个模板的累计使用次数、最近使用时间和使用趋势，帮助用户判断模板的热度与可靠性。
